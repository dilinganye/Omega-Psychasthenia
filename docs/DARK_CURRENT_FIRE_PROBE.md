# 暗流与火力侦察：实现、触发与 DevMode 观察手册

本文记录已实现的暗流（D-01～D-12）与火力侦察（P-01～P-12），并作为后续开发必须同步维护的 Dev 可视化说明。

## 1. 实际运行顺序

1. `DORMANT` 阶段抽取暗流事件。此时第四窥视尽量不公开出现，事件主要留下新闻、进度变化或玩家恰好在场时的碎片投影。
2. 进入 `RECON` 后，既有侦察舰队任务照常运行。
3. 满足以下任一条件后，随机池从普通侦察过渡到火力侦察：
   - `watcherAggression >= 22`；
   - `reconConfidence >= 36`；
   - 侦察阶段已经经过 42%。
4. 火力侦察事件中需要实际冲突的条目会建立 `FIRE_PROBE` 隐藏战略事件。远处仅作记录；玩家进入物化距离后才生成临时第四窥视舰队。
5. 临时舰队离开玩家附近后卸载回隐藏事件；到结算日后自动移除。影响和事件历史保留，不依赖实体舰队永久存在。

每张事件卡独立抽取，不依赖另一张具体事件已经发生。抽取目标无效时最多重试 12 次；仍失败则两日后重新抽取。

## 2. 随机差分

每次事件保存 `randomBranch = 0/1/2`：

- 分支 0：行动较早结束，数值效果乘以 `0.85`；
- 分支 1：标准结果，数值效果乘以 `1.0`；
- 分支 2：存在额外误差或矛盾报告，数值效果乘以 `1.18`。

分支会改变来源标签、标题、公开报道后缀、真实记录后缀及精确进度增量。公开新闻不保证正确；真实目标和真实文案只在 DevMode 中显示。

## 3. LunaLib 公开设置

非 DevMode 只显示以下内容：

| 设置 | 作用 |
| --- | --- |
| 潘多拉魔盒 | 默认开启。普通模式中，一个存档只要开启过危机便永久锁定为开启；DevMode 可自由暂停。 |
| 未知事件频率 | `0.1～5.0`。统一修正事件卡、侦察、扩张、要塞及战线回合间隔。 |
| 未知事件触发下限/上限 | 随机事件与侦察活动的基础间隔范围。 |
| 未知事件强度增值 | `0～200`，额外加入所有第四窥视/精神创伤实体舰队 FP。 |
| 未知事件强度倍率 | `0.5～10`，乘在基础 FP 上。 |

最终舰队强度仍使用统一入口：

`最终FP = 基础FP × 未知事件强度倍率 × 事件严重度倍率 + 动态Flat + 设置Flat`

动态 Flat 仍由危机阶段、精神创伤升级、巢穴发展及近期玩家行为计算，最大 `+200`；设置 Flat 可再额外增加 `0～200`。

## 4. DevMode 专用 Luna 设置

开启 DevMode 后，LunaLib 会动态增加“阶段”“侦察”“战略”“战争”“阶段开关”等分页；关闭 DevMode 后，这些字段会从界面移除，公开六类设置不受影响。

阶段开关包括：

- 暗流阶段；
- 侦察/火力侦察阶段；
- 沉寂营建阶段；
- 封锁与要塞阶段；
- 全面战争阶段。

阶段开关只在 DevMode 中生效。禁用当前阶段后，危机在下一次心跳跳到后续第一个启用阶段；若后续阶段全部禁用，则进入 `ENDED`。禁用全面战争会使危机在要塞阶段结束，不触发全面入侵警告和势力移交。

## 5. DevMode 直接触发

打开 `[DEV] 精神创伤危机监视器`：

- `强制抽取：暗流事件`：忽略当前阶段和事件卡冷却，随机生成一张 D 类事件；
- `强制抽取：火力侦察`：忽略当前阶段和事件卡冷却，随机生成一张 P 类事件；
- 每张事件记录都有“前往”和“到达”按钮；
- 事件列表同时显示公开报道、真实记录、随机分支、精确目标和数值效果；
- 有实体投影的火力事件还会出现在“战略事件”区，类型为 `FIRE_PROBE`。

代码级精确触发接口：

```java
PTSDCrisisIncidentManager.force("D-03");
PTSDCrisisIncidentManager.force("P-05");
PTSDCrisisIncidentManager.forceRandomCategory("暗流");
PTSDCrisisIncidentManager.forceRandomCategory("火力侦察");
```

## 7. 正常模式验收目标

1. 暗流新闻不显示真实坐标；只有玩家恰好在目标星系时才可能看到即时信息或残骸。
2. 新闻措辞保持原版 `rules.csv` 常见的观察式表达：先说明接收到什么、检查发现什么，再保留无法确认的部分。
3. 火力试探不是常驻舰队。远处事件只记录和结算，玩家接近才物化，离开后卸载。
4. 第四窥视舰队在正式战争前始终属于 `Omega_Watcher`；只有进入全面战争后才统一移交 `Omega_Psychasthenia`。
5. 关闭 DevMode 后，真实文案、精确坐标、强制触发按钮、阶段开关和内部参数均不可见。
