# 第二阶段终稿构想：侦察（RECON）

> 本文是侦察阶段的后续设计池，不代表以下内容已经实现。默认基础时长为 365 日。第四窥视仍是精神创伤的前入侵时代；只有正式全面进攻后才整体转为精神创伤。

## 1. 阶段定位

侦察阶段应是一整年的“隐形战争”，而不是每 10–25 日刷一支逃跑舰队。第四窥视需要逐步完成四件事：

1. 判断每个星系到底有什么、哪些情报可信。
2. 学习各势力如何调动、补给、追击和互相推诿。
3. 用小规模火力测试修正纸面结论。
4. 选择一批未来突破口、佯攻点、占领点和必须绕开的硬目标。

玩家则应能完成相反的四件事：发现观察方式、污染敌方数据、为殖民地建立预警、把有限资源投入未来真正会被攻击的地方。

阶段结束时，战争的初始战线应该是这一年双方行为的结果，而不是随机生成的一张新表。

## 2. 用“侦察完成度”替代纯时间到点

### 2.1 六个情报领域

建议把侦察完成度拆成六域，每域 0–100：

| 领域 | 样本来源 | 对开战的影响 |
| --- | --- | --- |
| 航路 | 跳跃点、超空间监听、商船航迹 | 进攻路线与到达时间 |
| 舰队 | 每日最高 FP、舰种、燃速、补给状态 | 突破编成与追击方式 |
| 殖民地 | 空间站、工业、稳定度、巡逻响应 | 目标价值和预计防御 |
| 指挥 | 求援延迟、援军来源、势力协作 | 佯攻、阻滞和多点施压 |
| 玩家 | 常用舰队、技能、逃跑/追击习惯 | 记恨袭扰与战前截获 |
| 物理 | 黑洞、裂隙、传感器盲区、可建设地点 | 前哨、要塞和异常投影 |

`RECON_CONFIDENCE` 应为覆盖率、样本新鲜度和相互验证后的派生值。单纯经过一天只增加计算预算，不直接增加可靠情报。

### 2.2 阶段结束规则

- 最短 365 日，防止危机过早爆发。
- 365 日后若总完成度不足，进入“延长侦察”，每 30 日复核一次。
- 玩家成功反情报、摧毁监听网络或持续更换舰队画像可延长阶段。
- 自然硬上限建议为 540–600 日；超过硬上限后第四窥视会接受不完整信息并承担更高误判率，避免永久卡局。
- DevMode 显示最短日、当前完成度、延长原因和硬上限；正常模式只通过事件语气表现“它们仍在确认什么”。

### 2.3 玩家延缓战争的代价

- 关闭通讯基站：降低对方通讯样本，但市场流通度下降。
- 调动假舰队：污染防御评估，但消耗燃料和舰船产能。
- 故意放走侦察舰：可追踪其返航方向，但它会带回更完整样本。
- 击毁侦察舰：阻断本次数据，却提高攻击性、对抗值和玩家画像。
- 公开真相：提高人类凝聚，也提高恐慌与第四窥视对响应链的了解。
- 压制新闻：降低恐慌，却让各势力无法共享证据。

这里不应存在永远正确的单选项。

## 3. 真正的欧米伽认知模型

### 3.1 三层数据

每个星系至少保存三层：

- `Truth`：当前真实市场、舰队、工业和路线，仅供后台结算与 Dev。
- `Belief`：第四窥视当前认为的数值，正式目标选择只读这一层。
- `Evidence`：支撑 belief 的样本列表，带时间、来源、可信度和污染标记。

权重更新时先让旧证据衰减，再融合新证据。没有侦察过的星系只能使用宽范围先验，不能读取真实市场防御。

### 3.2 情报老化

- 舰队样本 15–30 日快速老化。
- 殖民地工业 60–120 日慢速老化。
- 跳跃点与天体信息基本不老化。
- 玩家舰队画像在更换旗舰、主要武器比例或总 FP 后显著降置信。
- 侦察舰返航成功才提交完整样本；被击毁只提交此前通过窄束发送的部分。

### 3.3 主动学习

第四窥视不总选“最重要”目标，而应在三种需求间取舍：

- **利用**：继续观察已知薄弱、未来值得攻击的星系。
- **探索**：前往不确定性最高的星系。
- **验证**：复查与其他证据矛盾、疑似被玩家污染的星系。

这会自然产生看似聪明的行为：它可能绕开玩家严密布防的诱饵，也可能派一艘极小舰船验证那是否只是演习。

### 3.4 势力画像

除了星系表，建立势力级画像：

- 平均增援延迟；
- 常用舰种和舰队规模分布；
- 对边缘殖民地的放弃倾向；
- 被袭击后追击的距离；
- 新闻封锁或公开倾向；
- 对其他势力开放军事通道的概率。

后期攻击某势力时，根据其历史对抗值和画像生成专门编成，而不是只加 Flat FP。

## 4. 侦察舰任务系统扩展

### 4.1 任务选择

现有 RELAY、HYPERSPACE_WATCH、COLONY_INFILTRATION、WILDERNESS_ROAM 可扩展为：

| 任务 | 行为 | 主要分支偏好 |
| --- | --- | --- |
| 通讯寄生 | 环绕基站，间歇贴近结构阴影 | 介入灵质 |
| 航路截面 | 在两星系间多个点取样 | 介入灵质 |
| 舰队尾随 | 保持视距边缘跟随 NPC 或玩家 | 介入灵质 |
| 防线触碰 | 短暂进入巡逻拦截范围后撤退 | 网络冥魂 |
| 残骸回收 | 拆取武器接口与黑匣子 | 熵级运载 |
| 工程测绘 | 评估无人行星、黑洞与稳定点 | 熵级运载 |
| 诱饵投放 | 放置假求救、假航标或复制节点 | 乱码尸骸/介入灵质 |
| 反追踪 | 故意让玩家看见，再引向错误方向 | 乱码尸骸 |
| 多点同步 | 三支小舰在不同星系同时采样 | 单一随机分支，但共享任务组 |
| 火力标定 | 锁定、电子战、单轮齐射后撤退 | 网络冥魂 |

每支舰队依然只能使用一个分支，任务组可以包含多个分支，但必须在 Intel/Dev 中明确它们是独立舰队而非混编。

### 4.2 返航与数据提交

- 舰队应拥有“本地缓存”“已窄束上传”“返航完整包”三档数据。
- 玩家只看见它并不会自动让全部情报生效。
- 成功逃到远方后提交完整包；被迫提前撤离提交当前最大样本；被击毁只保留已上传部分。
- 玩家可在追逐中攻击通信节点而非舰体，降低数据提交但允许舰队逃走。
- 返航方向不必直指未来母星，允许经过 1–2 个一次性中继，防止轻易暴露基地。

### 4.3 行为适应

- 玩家连续用高燃速追击：侦察舰改用相位、诱饵和跃迁点两侧撤离。
- 玩家从不追击：侦察舰逐渐靠近，驻留时间增长。
- 玩家总能在基站抓到它们：转向无人星系和移动舰队。
- NPC 巡逻经常拦截：提前测试巡逻换班空窗，或制造假求援把巡逻引走。
- 同一任务失败两次：降低该任务权重，转用不同手段验证同一情报领域。

## 5. 玩家可获得的战后制衡能力

这些能力应在 RECON 中通过调查、打捞、Je 委托或势力合作逐步解锁，WAR 时成为真实战略工具。

### 5.1 情报类

- **窄束指纹库**：提前显示下一次进攻可能来自哪一侧，但不直接给目标。
- **敌方信念镜像**：战区 Intel 显示“欧米伽认为此处很弱/信息过时”，而不是显示真实攻击权重。
- **分支识别**：在接触前根据传感器噪声判断介入灵质、熵级运载、网络冥魂或乱码尸骸。
- **伪目标注入**：每 30 日可把一个己方星系的欧米伽估计防御提高或降低有限幅度。

### 5.2 战略类

- **基站净化协议**：降低星系被封锁时的人类响应惩罚。
- **分散式补给包**：使某支玩家特化舰队被切断后仍能维持一个回合。
- **幽灵集结点**：允许人类防御事件从错误来源显现，降低被伏击概率。
- **撤离优先表**：殖民地失守时保留更多人口/工业痕迹，减少恐慌连锁。
- **假旗舰计划**：高记恨时让一次消耗袭扰追错目标。

### 5.3 战术类

- **第四窥视火控样本**：第一次遭遇某类试探武器时给出短暂预警。
- **裂隙稳定信标**：有限降低某些危机战场环境的空间扭曲。
- **损毁协议残片分析**：战前研究越多，战后越容易获得专属奖励物品，但仍不掉落 AI 核心。

所有能力都应有来源记录，让玩家知道它来自哪次调查，而非突然出现在技能栏。

## 6. 侦察阶段事件池：早期（约 0%–30%）

### R-EARLY-01《它在等你转身》

- 玩家进入星系时，传感器边缘出现一艘介入灵质护卫舰。
- 玩家朝它移动，它维持距离；玩家背离，它缓慢靠近。
- 连续三次改变方向后，它留下一个无价值观测节点并消失。
- 结果记录玩家追逐耐心与燃速。

### R-EARLY-02《基站背后的第二层阴影》

- 通讯基站背面出现与结构不同步旋转的阴影。
- 只有传感器爆发瞬间能看见寄生节点。
- 摧毁、捕获或故意喂入假数据分别产生不同 evidence。

### R-EARLY-03《超空间中的平行航迹》

- 玩家自动导航时，旁侧出现一条始终平行的淡紫航迹。
- 航迹不会生成可接触舰队；改道两次后它才显露短暂源头。
- 可作为低成本可视化事件，不占活动舰队名额。

### R-EARLY-04《被扫描的海盗伏击》

- 玩家发现一支海盗舰队正在伏击另一支舰队，远处有未知接触同时观察双方。
- 第四窥视不参战；交战结束后才靠近残骸。
- 玩家可以先打海盗、驱赶观察者或完全不介入。

### R-EARLY-05《三次错误识别》

- 同一未知舰被依次识别为友军、海盗、余晖，最后才变成无势力信号。
- 每次身份切换都与附近最大舰队的敌对关系相适应。
- 表现其正在测试哪种伪装最能避免拦截。

### R-EARLY-06《空白的舰队名》

- 一艘高速护卫舰进入视距，目标面板只显示 FP 和燃速，名称、势力、任务均为空。
- 玩家锁定后信息栏逐项恢复，但内容来自玩家自己的舰队。
- 靠近到危险距离前它强制撤离。

### R-EARLY-07《中立的五支舰队》

- 扩展现有陷阱：五支舰队不是立即攻击，而是在不同星体间构成松散包围。
- 领队每隔数小时改变一次编队目标，其他舰队延迟复制。
- 玩家若攻击任意一支，其余舰队记录反应后同时撤退；若不攻击，它们在数日后无声离开。

### R-EARLY-08《通讯延迟实验》

- 第四窥视在两个基站间制造不同延迟，观察 NPC 舰队选择哪个求援信号。
- 玩家可修复其中一个，或交换两边标签制造错误样本。
- 未来战争中影响敌方对增援来源的判断。

### R-EARLY-09《被放回去的商船》

- 一艘失踪商船重新出现，货物、人员均在，但航行日志多出一套陌生的舰队编组算法。
- 玩家可护送其返港、隔离检查或公开出售算法。
- 三种选择影响恐慌、人类凝聚和敌方画像。

### R-EARLY-10《不会命中的警告射击》

- 一枚未知弹体从玩家舰桥前方掠过，落点总保持安全距离。
- 不进入战斗；弹道在大地图上留下短暂四向裂纹。
- 这是火力侦察前的视觉预告，不直接造成伤害。

## 7. 侦察阶段事件池：中期（约 30%–70%）

### R-MID-01《同一支舰队的三个版本》

- 传感器同时显示目标舰队位于三个位置，只有一处真实。
- NPC 巡逻会随机追错；玩家可用主动传感器缩小误差。
- 第四窥视记录人类如何在信息不完整时分兵。

### R-MID-02《被借用的增援》

- 某殖民地收到来自友方的求援，派出舰队后才发现请求来自不存在的舰体。
- 玩家可拦下增援、护送其返航或跟随假坐标。
- 假坐标可能有节点、残骸或一艘等待观察的侦察舰。

### R-MID-03《四十七秒封锁》

- 一支网络冥魂编队短暂占据跳跃点，恰好在当地援军进入武器范围前撤离。
- 每次差分根据真实响应速度决定停留时长。
- 若玩家在场，显示跳跃点周围逐渐收紧的紫色圆环和倒计时式脉冲。

### R-MID-04《防御平台的空炮位》

- 轨道站武器没有受损，却在未知舰进入射程时拒绝开火。
- 现场可见炮塔朝相反方向同步转动，持续数秒后恢复。
- 调查可解锁战时“人工火控隔离”准备。

### R-MID-05《海盗的公开投降》

- 海盗舰队向整个星系广播投降，对方却始终不回应。
- 未知舰只拆除其武器接口并离开，保留完整舰体作为样本。
- 玩家可以救援、打捞或追逐；每种行为都会被记录。

### R-MID-06《反向护航》

- 第四窥视小舰队在远处与一支民船保持相同航向，看似护航。
- 任何其他舰队靠近，它都会快速脱离；民船完全不知道其存在。
- 数日后民船原航路上的海盗据点被清空，原因不明。

### R-MID-07《假的薄弱点》

- Je 提议让玩家把一座边缘星系伪装成防御空虚。
- 玩家需调走舰队、关闭基站并放置假补给信号数日。
- 成功会吸引侦察；玩家若过早伏击，敌方识破并提高“人类欺骗概率”。

### R-MID-08《没有残骸的战斗》

- 玩家进入现场可看到两支 NPC 舰队正在交战，但战斗结束后所有残骸在数秒内向中心聚合并消失。
- 一艘熵级运载舰在远处完成回收后撤离。
- 这是让后勤分支显得有独立职能的事件。

### R-MID-09《测试你的补给》

- 一支小舰队连续制造传感器假阳性，引诱玩家多次紧急加速。
- 它不直接攻击，目标是观察补给下降和玩家何时放弃追逐。
- 若玩家保持静默航行或反向伏击，可降低玩家画像可信度。

### R-MID-10《航路被折成一条线》

- 多个跳跃点的导航箭头同时指向同一星系，持续一日。
- 实际跃迁功能不被破坏；只是 UI 与广播被污染。
- 玩家修复顺序会暴露其认为最重要的航路。

### R-MID-11《假旗舰》

- 未知编队中最显眼的舰船没有指挥信号；最小护卫舰才是实际协调节点。
- 击毁错误目标会让其余单位立即散开撤退。
- 玩家成功识别可获得分支指挥结构样本，战时降低一次敌方重组效率。

### R-MID-12《一场被观看的悬赏》

- 普通赏金目标附近出现第四窥视监听单元。
- 它会根据玩家战斗前编组、战后追击和维修选择更新玩家画像。
- 玩家可以放弃赏金换取反追踪机会，制造真正的玩法取舍。

### R-MID-13《无人的施工队》

- 无人星系出现熵级运载编队，对行星、稳定点和矿物逐一测量。
- 玩家靠近时它们不立即逃，而是先完成当前扫描并丢弃一次性节点。
- 节点可被逆向分析为未来前哨候选评分。

### R-MID-14《信道中的人类声音》

- 未知舰使用此前失踪船员的声音发出标准避让请求。
- 内容正确但情绪和停顿完全一致。
- 玩家回应会增加身份模型，不回应则可能错过坐标线索。

### R-MID-15《两边都以为自己赢了》

- 人类巡逻与第四窥视火力试探后，双方均主动撤离。
- 新闻根据当地势力宣传为胜利；现场弹道显示对方只完成了预定采样。
- 玩家调查可降低一次虚假凝聚，换取更准确的防御估计。

## 8. 侦察阶段事件池：后期（约 70%–92%）

### R-LATE-01《侦察舰不再逃那么早》

- 网络冥魂舰队允许玩家进入更近距离，甚至承受第一轮攻击后才撤退。
- 它在测试玩家武器组合和追击决心，规模仍不以歼灭为目的。
- 玩家会明显感到行为从回避转为自信。

### R-LATE-02《同时熄灭的三座基站》

- 三个相邻星系的通讯基站依次熄灭，形成向核心区推进的顺序。
- 战区图以三段脉冲线短暂连接它们。
- 玩家只能优先修复一座，决定哪条路线保持真实情报。

### R-LATE-03《被测量的联合舰队》

- 两个互相敌对势力因未知威胁短暂并航，第四窥视从多个方向抵近采样。
- 它不攻击，直到联合舰队试图分兵拦截；随后一支小队用火力阻滞，其他单位撤离。
- 记录跨势力协作可信度。

### R-LATE-04《用残骸画出的箭头》

- 6–12 艘残骸不再随机散布，而是组成指向某殖民地的巨大箭头。
- 箭头可能是真实目标、诱饵或对玩家行动的模仿。
- 正常模式不揭示真假；Dev 显示其所属假设。

### R-LATE-05《消失的巡逻空窗》

- 一座殖民地所有巡逻队恰好同时离港，却没有形成预期空窗；传感器上出现数量相同的未知替代回波。
- 靠近后回波散去，真正的第四窥视舰队从另一侧完成观测。
- 表现其开始主动掩护侦察行动。

### R-LATE-06《一次不合常理的仁慈》

- 未知舰队击瘫一支补给不足的民船，却留下足够物资让其返航。
- 物资容器本身持续广播民船修复速度和求援选择。
- 玩家可销毁容器、保留反向追踪或公开展示。

### R-LATE-07《玩家画像完成度》

- Je 告诉玩家，最近多起事件都在复现玩家曾使用的航线和战术。
- Intel 不显示精确百分比，只显示“零散 / 相关 / 高度一致 / 几乎完成”。
- 玩家可花费故事点执行一次全面更换签名，降低画像但不清除记恨。

### R-LATE-08《无人星系的舰队检阅》

- 玩家误入无人星系时，看到多支单分支舰队按严格间隔经过中心。
- 它们保持中立，不追击玩家；领队完成一次白光扫描后全体从不同跳跃点离开。
- 这是正式战争编成的第一次视觉预演。

### R-LATE-09《火力留下的刻度》

- 一颗无人行星表面出现数条精确等距烧蚀线，像舰炮校准尺。
- 轨道上有网络冥魂小舰队环绕观察。
- 玩家若攻击，敌方记录实战；若只扫描，可获得武器散布模型。

### R-LATE-10《第一个无法压下去的新闻》

- 同一影像从多个互不相连的新闻源同时发布，Je 无法全部封锁。
- HUD 新闻条连续滑过不同标题，最终合并成“未知舰体新闻属实？”
- 人类认知明显提高，普通充数新闻权重下降。

### R-LATE-11《边缘军演变成实战》

- 人类势力组织反侦察军演，第四窥视临时加入并以非致命火力打乱队形。
- 战斗可在玩家靠近时实体化；远方则以战略事件结算。
- 玩家表现能改善对应势力战时凝聚，失败则给敌方完整指挥样本。

### R-LATE-12《回程航线上的空白》

- 玩家追踪一支撤离侦察舰，航迹在连续三个中继节点处被切断。
- 每个节点指向不同星区外方向，只有一个携带真实数据。
- 让玩家选择追哪条，不允许一次全拿。

## 9. 临战事件池（约 92%–100% 与延长侦察末期）

此阶段应显著减少无影响新闻，让视觉、声音和 Intel 越来越统一。事件仍可独立抽取，但共享“临战”标签和全局冷却，避免一日内轰炸玩家。

### R-PREWAR-01《星区边缘的同步点火》

大地图边缘同时出现数十个极小白点，沿弧形由外向内点亮。它们不是实际舰队，只是远程跃迁/启动信号。数秒后全部熄灭，留下三条可能的进攻轴线。

### R-PREWAR-02《所有侦察舰同时返航》

现存侦察舰不再完成当前任务，统一进入撤离状态。玩家可在 2–4 日窗口内截击其中一支，尝试获得最后的数据包。其余单位在远处消失。

### R-PREWAR-03《没有新闻的一天》

新闻系统整整一日不生成任何普通新闻；已有标题逐渐褪色。次日恢复时，所有来源都只报道航路延迟和军方调动。沉默本身成为事件。

### R-PREWAR-04《边缘航标朝向同一点》

多个星系的导航浮标停止正常旋转，朝向星区外某一方向。玩家所在星系的浮标在其接近时发出白光并烧毁。战区 Intel 只显示一个宽阔扇区，不能直接暴露母星。

### R-PREWAR-05《联合红色草案》

玩家截获多当局尚未发布的红色警报草案，各势力版本措辞不同：霸主要求服从，速子称资产风险，联盟争论授权，教会称之为考验。玩家可以把草案交给 Je、提前公开或保持沉默。

### R-PREWAR-06《演习中的空位》

核心星域联合舰队演习画面中始终留有一个舰队大小的空位。镜头/星图缩放时，空位轮廓与某类精神创伤旗舰相符。没人承认排程里存在这个编队。

### R-PREWAR-07《超空间风暴静止》

玩家附近一小片超空间风暴短暂停止流动，形成通向边缘星区的笔直走廊。走廊内出现大批反向移动的细小粒子，像有舰队正在远方逆流集结。

### R-PREWAR-08《战线尚未存在，箭头已经出现》

战区态势 Intel 在数秒内闪现几条没有起点的进攻箭头，随后系统将其标为渲染错误。若玩家已有高情报准备，能够保留其中一条作为未来首轮预警。

### R-PREWAR-09《最后一次火力试探》

网络冥魂舰队对一个真正的军事目标执行完整但受控的突破：压制空间站、切断求援、在增援抵达前撤走。玩家若在场可参与三段式现场；远方则留下 60 日战场遗迹。

### R-PREWAR-10《高价值目标》

沿用现有战前截获门槛，但增强演出：

- 玩家首先看到航线前方的多个普通舰队同时避让；
- 传感器噪声形成朝向玩家的细线；
- 第四窥视小型截获队出现，目标显示“正在截获高价值目标”；
- 长时间未接触则主动脱离，被玩家击溃则记录最终战斗样本；
- 在事件解决前，全面入侵进度锁定；解决后 1–8 日内进入势力转换。

### R-PREWAR-11《八日倒数但不显示数字》

战前截获结束后，每日出现一种越来越明确的征兆：基站校时、航路保险停摆、军方静默、难民船启航、星区边缘白光、所有未知舰撤离、通讯空白、红色警报。正常模式不显示倒数数字，DevMode 显示 `warCommitDay`。

### R-PREWAR-12《第四窥视的终止》

最后一日，所有仍被玩家看见的第四窥视舰队短暂停止行动，舰队名和势力标记变为空白；随后恢复移动并消失。正式开战后再出现时，统一显示为精神创伤。该演出强调它们不是两个势力，而是同一主体结束伪装时代。

## 10. 火力侦察的结果类型

每次 P 类事件应产生明确结算，而不只是到期成功：

| 结果 | 条件 | 欧米伽获得 | 人类/玩家获得 |
| --- | --- | --- | --- |
| 完成采样 | 按计划接触并撤离 | 完整火控与响应样本 | 少量可见证据 |
| 提前中止 | 巡逻或玩家逼近过快 | 部分样本、提高风险估计 | 提升本地预警经验 |
| 成功逃逸 | 被追逐后脱离 | 玩家追击画像 | 可能追踪返航节点 |
| 舰队全灭 | 全部单位被毁 | 已上传残片、对抗值上升 | 技术残片、战争反制进度 |
| 诱饵成功 | 人类追错目标 | 指挥与分兵样本 | 若识破则污染敌方信念 |

同一火力事件的后续不应直接触发固定剧情，只修改 evidence、势力画像、局部恐慌和可选战时资产。

## 11. Je Otloes 在 RECON 中的深化

### 11.1 任务不只“去地点确认”

建议让 Je 的委托分成：

- 现场确认：找物证并降低当地恐慌。
- 反向跟踪：允许侦察舰逃走，追踪其中继链。
- 假情报投放：在指定基站维持数日，不被巡逻发现。
- 舆论处置：选择公开、压制或制造替代解释。
- 势力协调：把同一证据交给两个互相敌对的当局。
- 样本护送：把易失真物品送到友好港口，途中遭遇观察舰。

### 11.2 信任与能力

Je 任务完成数不只用于解锁相关器，还可以形成三个隐藏方向：实地信任、政治网络、技术样本。不同方向决定他在 WAR 中能提供预警、舆论压制或反制装置。

### 11.3 后期焦虑差分

- 早期：带嘲讽、把事情说成麻烦的传闻。
- 中期：开始同时处理多个势力，回复更短。
- 后期：背景中不断有人递交新报告，通讯偶尔被强制中断。
- 临战：他不再掩饰恐惧，只要求玩家选择一件最重要的事去做。

## 12. 人类方面的响应事件

### H-RECON-01　霸主“统一编号行动”

霸主试图给所有未知接触统一编号，实际导致地方报告被错误合并。玩家可帮助建立更准确分类，提高凝聚但让霸主掌握更多情报。

### H-RECON-02　速子“风险证券化”

速子把未知接触风险打包成可交易产品，短期降低企业恐慌，长期可能让一次假消息造成市场连锁。

### H-RECON-03　联盟“共同防御但各自指挥”

成员世界同意共享传感器，却拒绝共享舰队指挥。第四窥视可故意在边界制造同时求援，测试谁会先违约。

### H-RECON-04　教会“静默朝圣”

朝圣船关闭应答器穿越异常航路，意外成为低特征观察样本。玩家护送可获得反画像经验。

### H-RECON-05　左径“向虚空开火”

左径分子攻击疑似监听节点，可能真的命中，也可能摧毁人类基站。新闻真假与现场结果分离。

### H-RECON-06　海盗“卖出同一坐标”

海盗把同一未知坐标卖给多个势力，并在买家抵达时伏击。第四窥视在远处观察多方混战。

### H-RECON-07　独立世界“航路互助网”

多个独立市场自建黑匣子互证网络。玩家可投入物资使其成为战时预警节点，也可能被未知代码寄生。

### H-RECON-08　余晖误判

一支余晖编队把第四窥视当作未知自动化威胁并追逐。双方不会留下普通可打捞战利品，但可形成独特传感器记录。

## 13. 战区 Intel 在开战前的表现

侦察阶段不应提前显示完整冷战战线。建议逐层解锁：

1. 只有新闻点和十日目击标签。
2. 出现模糊“观测走廊”，宽度代表不确定性。
3. 玩家取得信念镜像后，可看到第四窥视认为的薄弱区，但不能看到真实数值。
4. 临战时出现 2–4 条可能进攻轴线，每条显示置信等级而非百分比。
5. 战争爆发后才把这些轴线转成正式战线；若前期情报被污染，敌方第一轮可能沿错误轴线行动。

可视化建议：

- 低置信情报使用断续细线和漂移端点。
- 已验证路线使用稳定紫线。
- 玩家伪造的信息用人类侧才能看见的青色噪点标记。
- 即将过期的样本逐渐失焦，而不是瞬间消失。

## 14. 新闻系统的阶段适配

- 0%–30%：普通新闻仍约占 52%，异常报道混在正常社会新闻中，真实位置模糊且无人主动串联。
- 30%–70%：充数降至 15%，侦察与势力响应新闻并行。
- 70%–92%：充数降至 5%，同源指纹和火力事件增加。
- 92% 以后：不再生成纯笑话式充数新闻，只保留战争准备、撤离、金融异常与官方反应。
- 同一新闻在不同阶段可用不同 `report/truth/siteTemplate`，但不应重复创建同一实体场景。
- 假消息也可以持续后台调查，但能力不得泄露其精确真实目标；30 日硬过期仍保留。

## 15. 性能控制

- 普通侦察舰全局上限与玩家周边特殊事件上限分开计算，但总活动危机舰队仍需硬上限。
- 远方侦察只保存路线阶段、样本和预计抵达日；玩家进入相关星系才创建实体。
- 多点同步任务在后台可代表三支舰，玩家只会在一个地点看见 1–2 支代表舰队。
- 侦察舰离开玩家渲染范围后不必继续逐帧寻路，可转换成后台行程。
- 残骸事件优先使用 debris field；代表性舰体不超过 3 艘。
- 临战大型演出主要使用地图覆盖、粒子、声音和短时 token，不一次生成数十支真实舰队。

## 16. DevMode 与可测试接口

### 16.1 必看数据

- 六域侦察完成度；
- 每星系 Truth / Belief / 误差 / confidence / lastSeen；
- evidence 来源、污染状态、剩余有效日；
- 势力画像与玩家画像；
- 当前探索/利用/验证倾向；
- 阶段最短日、延长天数、下一复核日、硬上限；
- 战前截获是否生成、是否解决、`warCommitDay`。

### 16.2 强制触发

每个大事件和特殊事件应有独立表头，至少支持：

- 强制创建任务但不物化；
- 前往目标；
- 到达安全点；
- 强制“完成采样 / 中止 / 逃逸 / 全灭 / 诱饵成功”；
- 切换证据真/假/被污染；
- 强制提交本地缓存、窄束包或完整返航包；
- 强制进入延长侦察；
- 强制执行临战八日演出中的任意一天；
- 重置 Je 冷却并指定任务类型；
- 授予或移除各项战后制衡资产。

### 16.3 事件记录格式

建议统一为：

```text
[事件ID] [阶段百分位] [目标]
公开：玩家看见的内容
真实：实际发生的内容
Omega：获得/失去的 evidence 与 belief 变化
Human：恐慌、凝聚、防御准备变化
Player：画像、奖励、可用反制变化
实体：fleet/token/wreck IDs，安全点，清理日
```

## 17. 推荐实现顺序

1. 先把 Truth、Belief、Evidence 分层，解决当前攻击权重重算覆盖问题。
2. 让侦察舰的数据提交与生死/撤离结果关联。
3. 实现六域完成度和 365 日后的柔性延长。
4. 加入 4–6 种玩家反情报操作，确保延缓战争有代价也有回报。
5. 为火力侦察补齐五类结算。
6. 先实现早/中/晚各 3 个高辨识度事件，再扩充到完整池。
7. 最后制作临战地图演出、八日无数字倒数和第四窥视到精神创伤的转换演出。

这样能先让“聪明”成为真实的数据行为，再用新闻和可视化把行为展示给玩家，避免只有华丽事件、后期战略却仍然随机。
