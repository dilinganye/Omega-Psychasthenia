# PTSD_Fracture_Cross 测试说明

1. 在 DevMode 装配 `PTSD_Fracture_Cross`（隙质弩）。
2. 对空射击时，每发弹体应只显示一个随弹体移动的四尖极坐标裂隙。
3. 弹体进入敌舰约 560 距离后应转向并加速，裂隙沿飞行方向拉成长椭圆。
4. 命中后应形成约 185 范围、持续约 4.2 秒的骇入云；云内敌方武器会被反复禁火并延长冷却。
5. 连续速射同一位置时，云会合并并略微扩大；全场同时最多维护 8 团云。
6. 检查友方武器不受骇入，装饰武器和永久损毁武器会被跳过。
7. 朝空处开火并让弹体自然飞出武器射程：引擎熄火后应只触发一次小型裂隙爆炸，爆炸恰好包住消失前的双层裂隙长轴，同时出现一圈约 `0.18s` 的空间波动。
8. 正常命中舰船或弹体被击毁时不应触发上述“超程消逝”爆炸，也不应额外生成骇入云。

性能观察：大量齐射时不应为同一弹体持续创建裂隙实体，也不应无限叠加命中云。
