# PTSD_Intertitial_Injection 实现与测试

## 武器行为

`PTSD_Intertitial_Injection` 现在使用独立的 `PTSD_Intertitial_Injection_shot`，不再复用普通塔罗弹体。

- 弹体是不可见的自导导弹，使用自定义 `MissileAIPlugin + GuidedMissileAI`。
- 优先跟踪发射舰当前锁定目标，否则在1450范围内选择最近的敌对非战机目标；允许诱饵通过标准接口改写目标。
- 转向中加入小幅摆动，模拟原版 Churning Locus 的松散卷动，而不是普通导弹的刚性直线追踪。
- 下层渲染三层缩小版黑紫云体；上层使用 `graphics/fx/radial_EX.png` 渲染双层反向旋转、缩放脉动的裂隙核心。
- 飞行期间每0.11～0.165秒生成局部Negative反色场，并持续留下黑紫云雾。
- 命中时保留反色场和裂隙爆发，并通过独立 `spawnCompactImpactMist()` 生成四团紧凑Negative云雾；单团基础尺寸28～52、扩张倍率1.25、持续0.48秒。实际范围伤害由弹体 `explosionSpec` 结算。
- 发射器保留现有武器贴图、弹药、射程和装配数据，只替换独立弹体与视觉/追踪实现。

## DevMode测试

1. 在模拟战装配该武器，并分别锁定静止舰、快速护卫舰和战机；弹体应优先维持主目标，目标失效后重新选敌。
2. 从弹体侧面观察：实际导弹贴图和引擎辉光不可见，只能看到下层云体、上层裂隙核心和局部反色。
3. 让目标横向高速移动，确认裂隙核心始终跟随弹体，而不是停留在发射点或旧坐标。
4. 使用诱饵干扰，确认 `GuidedMissileAI.setTarget()` 可以改变跟踪目标。
5. 命中舰船和小行星，确认命中位置生成扩大反色场与裂隙爆发，且插件在弹体移除后不残留。
6. 同时发射多枚弹体，观察帧率和Negative效果数量；每枚弹体只有一个主视觉插件。

## 当前贴图状态

当前实现不需要新增资源：云雾使用原版 `misc/nebula_particles2`，裂隙核心使用模组已有的 `graphics/fx/radial_EX.png`。若后续需要更复杂的活体裂隙，可提供一张4×4逐帧图集，建议单帧128×128、透明背景、中心保持固定、外围保留至少12像素透明边距。
