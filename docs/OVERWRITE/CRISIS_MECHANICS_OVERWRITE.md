# 精神创伤危机机制覆盖规格：沉寂、侦察与后续阶段接口

> **覆盖关系**：本文是沉寂、侦察与恐慌机制的依据，优先于 `docs/FINAL_DORMANT.md`、`docs/FINAL_RECON.md`、`docs/CRISIS_PROGRESS_API.md` 和 `docs/INVATION_IDEAS.md` 中相冲突的规则；旧文档仍供剧情、事件和现有 API 参考。后期战略资源、要塞和总参部以同目录 `FORTRESS_WAR_MECHANICS.md` 为准，后期剧情与事件文字以 `FINAL_FORTIFICATION_WAR.md` 为准。特别是本文旧的“准备度 55”已被后期真实/估计准备点双账覆盖。本轮只撰写规格，当前 Java、CSV、存档格式和游戏行为均未修改。

## 1. 设计目标与不变条件

1. `DORMANT` 是 **120 日**正常社会基线。没有第四窥视侦察、隐藏敌方认知、暗中目标权重或被动积累的战争优势；阶段切换不向玩家宣告。
2. `RECON` 最短 **365 日**，证据成熟后进入 `EXPANSION`；第 **800 日**强制以当时的不完整情报推进。玩家可以延误、污染、利用侦察，不能令危机永久停滞。
3. 敌方只能据已取得且仍有效的证据行动。人类公开新闻、玩家单方面目击、后台世界真相和敌方自身样本是四种不同的信息。
4. 恐慌仍然以殖民地为主要单位造成失序、贸易和防务损失。符合局部绝境条件时可能产生短暂的组织性抵抗；经济损失并不因此消失。
5. 第四窥视与精神创伤是同一主体的前后时代。营建、要塞和公开动员继续消耗同一个敌方预算；`WAR` 才切换对外势力与全面战争 UI。
6. 普通玩家不见数值、精确阈值和敌方真实信念，只见定性区间、近期变化原因及由证据支持的地图判断。DevMode 须能追溯每一次推断和资源调配。

## 2. 信息分层：谁知道什么

| 层 | 所有者 | 记录什么 | 能被谁读取 |
| --- | --- | --- | --- |
| `GroundTruth` | 战略结算器 | 实际市场、舰队、航路、设施和控制状态 | 人类侧远程结算、测试与 Dev；不得作为敌方选点输入 |
| `OmegaEvidence` | 第四窥视/精神创伤 | 亲自采到、窄束送达或完整返航的数据 | 敌方信念汇总与行动规划 |
| `OmegaBelief` | 敌方 | 从证据推断的目标价值、防务、路线和不确定性 | 敌方选点、编成、佯攻与调兵 |
| `HumanReport` | 人类各机构 | 新闻、目击、打捞、军方报告及其验证、传播范围 | 人类认知、协调、恐慌和玩家 Intel |
| `PlayerAnalysis` | 玩家与合作网络 | 已记录线索、证据链、判断和反情报能力 | 玩家 UI 与可执行反制，不自动交给所有人类势力 |

一则公开新闻不是敌方侦察结果；同样，玩家看到一艘侦察舰也不是所有殖民地都已确认危机。仅当侦察舰的传感器实际接触玩家，才可记入敌方玩家画像。敌方若监听到人类公开报告，须把这次监听作为独立的低可信证据记录。只有报告经过提交、转发或玩家主动共享，才提高接收方的人类认知。普通新闻可以引发恐慌，即使后来被证伪；证伪后应撤销该条新闻尚存的恐慌贡献。

### 2.1 敌方证据记录

未来记录至少包含 `systemId`、六域之一、`sourceType/sourceId`、观测值、可信度、采样日、过期日、上传状态、是否被玩家污染和独立来源组。上传状态仅有 `LOCAL`、`PARTIAL_UPLOADED`、`CONFIRMED_UPLOADED`、`LOST`：本地缓存仅供该舰任务行为，不能驱动全星域决策；已上传的部分只贡献实际上传字段；返航后完整包才取得全部样本；舰队被毁后未上传部分丢失。

同一任务组的重复样本只取最可信的一份参与置信度融合，防止一艘船在原地反复上报刷满进度。每条证据按类型过期：机动舰队与玩家画像 20–30 日，殖民地设施及编制 90–120 日，固定航道和天体测绘原则上 180 日以上；遇到实地变化应立即使相应旧样本失效。污染样本并非简单打七折；在未被识破前可改变敌方的估计值，被独立验证后才标记为冲突并降低其权重。

### 2.2 六类侦察域

| 领域 | 合法样本 | 后续用途 | 玩家主要反制 |
| --- | --- | --- | --- |
| 航路 `ROUTE` | 跳跃点通过、超空间航迹、实际监听节点 | 首波轴线、到达时间、封锁位置 | 换路、拆节点、诱饵航迹 |
| 舰队 `FLEET` | 接触到的舰体、火力、燃速和补给行为 | 战术编成、追击与正面强度估计 | 更换编成、拦截上传、伪装集结 |
| 殖民地 `COLONY` | 市场、设施、轨道防御的实地样本 | 目标收益、防线与撤离估算 | 隐藏建设、临时空置、假目标 |
| 指挥 `COMMAND` | 求援与增援响应、不同势力协作 | 佯攻、阻滞和调兵时机 | 分散通讯、预先授权、共享互证 |
| 玩家 `PLAYER` | 对玩家舰队的有效接触和可验证战绩 | 针对玩家的威胁评估与截获 | 改变行动模式、截断数据、诱饵 |
| 物理 `PHYSICS` | 黑洞、稳定点、异常设施的测绘 | 母星、要塞和环境行动的可行性 | 摧毁工程链、污染坐标 |

单域置信度由**尚有效、已上传且含该域实际观测值**的独立证据融合；无观测字段的新闻记录不能提高它。默认融合方式为 `100 × (1 − ∏(1 − min(0.35, 证据可信度 × 新鲜度 × 上传完整度)))`，每个独立来源组只保留最大一项，因此一次任务对单域的贡献上限为 35 点。`PARTIAL_UPLOADED` 的上传完整度只按实际传回的字段计算，`CONFIRMED_UPLOADED` 为 1。数值观测使用按可信度加权的中位值；彼此矛盾的独立样本须降低结果置信，并优先触发复查而非自动选取较有利的值。长期固定信息与机动信息各自衰减，不用同一张 120 日新闻替代全部侦察。

### 2.3 侦察完成与阶段门槛

全局“侦察置信”不再是可直接 `add()` 的经验条，而是五个非玩家领域在**敌方已知且仍可能成为目标的星系**中的加权覆盖汇总。星系权重只由敌方先验和自身证据产生；未知星系不得因 `GroundTruth` 中有大市场而自动获得高权重。`PLAYER` 域独立决定个性化行动，不阻塞阶段转换。

`RECON` 在第 365 日后每 30 日复核：五域平均覆盖至少 60，且至少三域达到 50，并有一条经实地验证的航路和一个经实地确认的目标或可建设地点，才进入 `EXPANSION`。如第 800 日仍不满足，强制进入营建，但把缺失域记录为战略盲点：未来首波更易错判，需分配额外侦察预算。强制推进不凭空补满任一领域。阶段结束只改变后台行动；玩家仍需通过现场与报道察觉侦察舰的撤离。

## 3. 全局指标的重定义

下表定义未来模型的**意义**，而非要求保留现有枚举名。除恐慌外允许破坏旧 `PTSDCrisisProgressAPI`。汇总值用于 Dev 诊断、粗粒度解锁和玩家定性文本；局部行动必须读取对应地区的证据与资源。

| 旧指标/字段 | 新意义或替代 | 来源、变化与可读性 |
| --- | --- | --- |
| `RECON_CONFIDENCE` | 五域局部证据的只读覆盖摘要 | 由有效上传证据重算，会因过期与冲突下降；敌方不得拿全局值当某星系的精确信息 |
| `HUMAN_AWARENESS` | 已传播且被验证的危机认知摘要 | 各市场/机构持有不同报告；新闻引发讨论不等于已核实，玩家交付资料后才沿通讯网传播 |
| `WATCHER_AGGRESSION` | 移除单调增长，改为地区/目标行动姿态：观察、试探、惩戒、撤回 | 由任务损失、敌方预算、证据可信度和目标收益决定；追击玩家可提高局部警戒，不能使全图无条件升级 |
| `NEST_DEVELOPMENT` | 现存前哨与设施带来的生产、维修能力 | 建设成功增加，受轰炸和设施失效减少；不能每天凭阶段免费增长 |
| `BLOCKADE_DENSITY` | 已部署节点及巡逻覆盖的航道网络摘要 | 拆节点、转兵或补建即重算；局部封锁只影响其能覆盖的边或星系 |
| `OMEGA_ESCALATION` | 战时已承诺的兵力与异常资产比例 | 从预算账本派生；高投入意味着其他方向储备不足，不是全军永久增强倍率 |
| `HUMAN_COHESION` | 实际情报共享、互认指挥与可到达增援的网络摘要 | 由协议和成功协作提高，争执、通讯损失及背弃削弱；不因进入 WAR 自动上升 |
| `REALITY_DISTORTION` | 各区域现存异常环境的强度，另提供全局摘要 | 来自可定位设施与事件，有范围、持续时间和清理结果；不按日自动全域增加 |
| `GLOBAL_PANIC` | 少数全星域剧情刺激的加成，默认 0 | 延续现有特殊事件入口；普通新闻和近距威胁只改局部恐慌 |
| `playerGrudge` | 由六维玩家证据档案替换 | 火力侦察起的正面战力、要塞破坏、战线救援、补给能力、机动和欺骗样本分别记录；全维合成只决定注意力投入，后期详见 `FORTRESS_WAR_MECHANICS.md` |
| `factionResistance` / `learningMultiplier` | 已获取的对抗战术记录 | 需有已上传战损或观察资料；允许换战法和重新分配预算，不直接加固定 FP |

`DORMANT` 不生成上述敌方指标的正向变化。`RECON` 的“舰队抵达任务区”先生成本地缓存；“玩家目击侦察舰”只影响玩家所知和可传播的人类报告；“侦察舰成功逃脱”只提交确实携带的数据。新闻 CSV 当前的 `recon`、`awareness`、`aggression` 列未来须改为**显式来源的效果声明**，不能再把一条公开新闻同时当成敌方证据、人类认知和目标偏置。剧情正文与真假分支保留。

### 3.1 有限战略预算

用 FP 等价的战略预算记账，但不把它直接当作实体舰队总 FP：`可用储备 = 现存产能积累 − 已部署任务 − 建设施工占用 − 维修占用 − 未补足损失`。侦察时代带有限的远征初始储备；存活并返航的舰船归还可用份额，被击毁的份额需在前哨形成后重新生产。母星和设施提供有上限的恢复能力，轰炸能影响后续恢复而非立即删除全图舰队。

每个战略事件在计划时预留预算，远程结算或实体战斗结束后根据幸存与损失回收；取消的事件释放预留，不能重复退款。侦察、建设、卫戍、佯攻、正式进攻和针对玩家的行动使用同一账本。敌方若抽调守军追击玩家，原守备区在下一个战略回合出现更低的防御或更高的被突袭概率。预算不足时允许低成本观察、撤退或放弃目标，不凭空补强舰队。

后期不使用单一战争准备度百分数或 55 门槛。可积累、可支付的真实准备点与敌方对自身准备的估计分开保存；设施提供有限产出，截运和欺骗可使两者偏离。常规路径是 `FORTIFICATION → MOBILIZATION → WAR`，高真实准备或有下限约束的误判允许直接突袭进入 `WAR`；第 180 日仍须沿常规路径推进，不能永久卡住。详细产出、支出和门槛见 `FORTRESS_WAR_MECHANICS.md`。进入战争不自动把侦察置信、巢穴发展或人类凝聚抬到固定地板。

## 4. 人类恐慌、组织与背水抵抗

局部实际恐慌继续由 `eventPanic + 已被人类认知的近距威胁 + GLOBAL_PANIC` 组成，范围 0–100。未经公开确认、无人能感知的隐藏母星或控制区，不得仅靠地图距离增加人的恐慌；一旦难民、航道禁令或可靠目击传开，近距威胁才可参与计算。被证伪新闻的存余贡献可撤销；已经造成的短期市场波动不倒转历史。

保留现有常规基线以供调参：每点局部恐慌约降低 0.65% 流通度、最多降低 65%；星系恐慌压低防卫舰队规模倍率、最低 25%；约 30 以上有总数受限的趁乱海盗。后续可增加有来源、有期限的抢购、误疏散、兵员离队或求援延迟，单一事件不得把所有惩罚同时堆满。普通玩家看到原因和方向，不看到具体系数。

**背水抵抗**只在一次具体围困中判定：市场恐慌至少 65；预计一个战略回合内没有友军增援可达；当地仍有可工作的指挥链、民间互助网络或玩家事先组织的防务；有真实进攻或撤离压力。每次围困只触发一次，持续一个战略回合，同市场 60 日内不重复。加成：防线阻滞时间提高约 25%，可撤离人口或资产提高约 15%，守军溃败概率下降约 20 个百分点；原有市场流通度与舰队规模惩罚照常计算。

若存在实际守备舰队，再以事件 ID 固定随机结果判定一次军官表现强化：基础概率 20%，恐慌超过 65 后每点增加 0.5 个百分点，上限 40%；成功仅将现有守军的一名合格军官提高一个临时有效等级或等价战术质量，事件结束即清除，不增加舰船或复制军官。没有守军时只结算阻滞与撤离，不虚构舰队。公开文本可称“没有撤退地点的守军比命令预计多守了数小时”，不能写成恐慌天然令人勇猛。

DevMode 必须显示触发所依据的恐慌、孤立、组织和救援到达日；不满足条件时说明哪项未达。人类凝聚的全局汇总不能代替当地组织状态。玩家提前建互助网、交付补给或修复通讯可创造抵抗条件，也可能因撤离得更早而使“绝境”条件消失；两种结果都应被视为成功的救援方式。

## 5. 玩家反情报与可见信息

调查、记录新闻、追踪侦察舰、交战和交付物证继续是基础入口。另设与阶段**相对独立**的反情报能力，只有经验证的现场、截获数据、成功识破污染或共享互证才提高；阅读大量新闻标题不刷能力。三个解锁档位以后台 20/50/80 的能力值判定，普通玩家只看到“可追踪来源／可比对冲突／可组织反制”的文字：

1. **来源追踪**：在已记录调查中显示消息出处与最近变化原因，不给敌方真实目标。
2. **冲突比对**：将两个独立来源的矛盾标在 Intel 上，可选择公开、交给 Je 或交给另一机构；决定影响传播和恐慌。
3. **资源分配**：开放小型情报与反情报页，同时最多三项行动，供玩家对已知监听节点、假目标和情报共享进行投入；行动须有已取得的证据作为依据，并占用有限分析人手，有 30 日同类冷却。证据不会因使用一次而从记录中删除。

Je 可更早解释一条线索、提高一次行动效率或提供额外调查路径，但不独占任何档位。未认识 Je 或其死亡后，玩家的已有能力与行动不消失；后续联合警戒网、地方分析员或自有殖民地网络承担必要结算。普通玩家只看到定性置信区间（未核实／线索较弱／多源互证／高度可信）和最近变化原因；即使进入 WAR，也不显示精确敌方预算或 0–100 数值。DevMode 展示每个来源、到期日、传播范围、预算预留和旧值迁移记录。

## 6. 事件卡与后续阶段的机械契约

| 文案或现有事件 | 合法机械输入 | 主要结算与禁止的捷径 |
| --- | --- | --- |
| DORMANT 普通新闻、D-01～D-12 | 人类事件或误报，允许局部恐慌 | 不生成第四窥视证据；RECON 的同标题真实分支才可进入敌方侦察链 |
| RECON 目击、追逐、火力试探 | 实际视距接触、战斗结果、上传状态 | 火力侦察起测试玩家反应并建立有来源的六维档案；玩家看见敌方不自动给敌方加侦察，摧毁舰队只保留已上传数据 |
| `FT-03` 商队诱追、`FT-04` 母星驻留 | 实际现场接触与玩家追击或近轨道活动 | 诱追与母星守卫须先占用真实舰队资产；FT-03 不再以三次重复航路为门槛 |
| `FT-05` 幸存舰残缺航迹 | 真实异常接触、残片出示或逐次报价 | 线索只指向可搜索区域；真实编队仍按舰队资产结算，不替玩家解释用途 |
| `MB-02` 假战线、`WR-01` 首波名单 | 局部信念、实际准备点及战略预算 | 假信号和真主攻均需成本；被污染情报可使敌方跳过动员而误判突袭，实际舰队仍按真实资源产生 |
| `WR-04` 总撤退、`WR-05` 补给干扰 | 已取得的战败或玩家补给链证据 | 战区重分配须先释放旧部署；未侦得补给港不能精确断供 |
| `WR-06` 孤立殖民地、`WR-09` 防御成功 | 实际增援可达性、恐慌、组织与战损上传 | 分别检查背水抵抗和敌方学习；人类胜利不免费强化敌方 |

事件至少记录其使用的证据 ID、预算预留 ID、公开报道、玩家可见征兆、反制窗口、结果及下一回合权重变化。失败生成点、目标被其他模组删除、新闻过期或外部舰队消失时，只结算已有事实并释放预算，不能生成幽灵证据或重复退款。

## 7. 面向后续开发的接口与迁移

建议新存档模型把 `EvidenceRecord` 扩展为明确的 `domain`、`uploadState`、`sourceGroup`，把 `HumanReport` 与敌方证据分开，并增加每地区信念、预算账本及当地组织状态。`PTSDCrisisProgressAPI.Snapshot` 只提供派生摘要、阶段与定性可见性；外部写入必须走明确的“提交敌方证据”“传播人类报告”“建设/损失/部署预算”操作。旧的 `add(RECON_CONFIDENCE)`、`add(WATCHER_AGGRESSION)` 等可破坏移除，不保留会再次制造混用的兼容写入口。恐慌仍通过 `PTSDLocalPanicAPI` 的局部与特殊全局入口管理。

迁移旧 Alpha 存档时提高状态版本并一次性记录迁移标记：

- 保留阶段、阶段已过天数、殖民地恐慌贡献、已完成调查、实际舰队/市场/设施和可核对的旧证据；近距恐慌按新认知规则重算，不把旧距离加成永久固化。
- 旧 `EvidenceRecord` 有可识别来源及实测字段时映射到相应领域；无法判断领域、上传状态或来源的样本置为未验证，不用旧全局侦察值伪造一批满置信证据。
- 以实际存在的前哨、要塞、舰队和事件重建预算初值；未落实到资产的旧 `nestDevelopment`、`blockadeDensity` 与 `playerGrudge` 只留作 Dev 迁移备注。
- 保留已记录的玩家新闻与 Je 状态；新反情报能力从可验证的调查历史估算。若资料不足，降低到仍能使用基础调查的档位，不剥夺已取得的独特物品。
- 迁移当日不跨越多个阶段：超过新门槛的旧 RECON 存档先获得至多 30 日的复核窗口，之后按成熟度或第 800 日硬上限进入营建；已在后续阶段的存档不倒退。
- 旧 `PUBLIC_PANIC` 只作为一次性 `GLOBAL_PANIC` 迁移来源；不得和已有全局恐慌重复相加。DevMode 列出保留、推断及清零的字段。

迁移实现和新 API 可不兼容旧外部模组调用，但须在开发文档中明确版本变更和替代入口。当前 Alpha 的侦察内容上限保持独立；这些机制规格不自动开启尚未完成的后续阶段。

## 8. 验收情景

1. **沉寂 120 日**：大量普通新闻仍不改变敌方证据、目标权重和预算；未发现的母星不制造近距恐慌；第 120 日切换无玩家可见高潮。
2. **无人接触侦察舰**：敌方只能通过自己实际完成并上传的任务累积五域，玩家没有凭空获得敌方位置；第 800 日必能继续，即使覆盖不足。
3. **玩家反复追击**：敌方若上传了玩家舰队样本可改姿态或部署诱饵；被击毁且未上传的资料不能参与未来精准截获，玩家反制亦有资源代价。
4. **被污染的新闻与假目标**：公开报道影响人类认知或恐慌，只有独立物证才能教会敌方；被污染的敌方样本应造成可追溯的错判和复查。
5. **战线重分配**：敌方把兵力从某防区投入玩家追杀后，原防区至少一个战略回合出现可利用的弱点；失败结算不凭空提高全军 FP。
6. **恐慌与背水抵抗**：高恐慌但有援军、无组织或无进攻时只有常规负面；孤立而有组织时短暂增强阻滞与撤离，市场经济仍受损，军官强化不增加舰船数。
7. **独立反情报 UI**：高强度调查可在相对早期解锁较高档位；从未见 Je、Je 存活、Je 死亡均可使用必要功能和收到同等关键战报。
8. **旧存档**：真实证据与恐慌保留，无法还原的认知清零并在 DevMode 说明；不会因旧全局进度过高当日连跳数个阶段。
