# 战略资产奖励与地表产线运行规则

本规则覆盖此前文档中仅由母星、据点和要塞恢复战略资产的数值描述。战争准备点仍使用原设施产出、成本和阶段门槛，不与本规则互换。

- 侦察舰启航时按生成后的实际舰队自动分占用战略资产。每艘舰队对每个星系的首次实地报告成功上传，奖励战略资产 5 点；重复驻留报告不重复奖励。安全逃离或正常完成撤离时，按当时幸存舰队的自动分返还战略资产。上传前被击毁的报告与未成功撤离的舰队均不返还。旧档中的在途侦察舰无法追溯出航支出，但仍按本规则结算之后实际上传与撤离。
- 精神创伤战略事件仅在结算为成功时奖励 5 点；要塞运输实际到站、移动要塞实际抵达、现场回收舰实际抵达物件时也各奖励 5 点。每项任务使用唯一 ID 防止读档、重复回调或重复查看 Intel 再次发奖。失败、取消、目标消失与舰队提前全灭不发成功奖励。
- 扩张、要塞化期间，当前处于精神创伤实控区且实际归其所有的星球一次性标记为完全开发，设为最高改造等级，并叠加紫色工业灯光纹理。标记随星球保存；失去控制权后不再提供战略资产。新占领星球在下一次危机结算中补齐开发状态。
- 每次正常生产结算，所有实际受控星球各提供战略资产 5 点；其中具有完整产线标记的星球再提供 10–20 点。额外值按星球 ID 和结算序号稳定抽取，账本逐颗列出。原有设施的战争准备点产出和基础战略资产恢复继续存在。战略资产存量上限为 5000 点；达到上限时记录应收与实际入账差额。
- DEV 面板显示当前资产、最近一次任务回收、生产结算中的逐星球贡献。游戏内 LunaLib 仍控制原有建设与战争难度；本轮星球的 5 与 10–20 为固定规则。
