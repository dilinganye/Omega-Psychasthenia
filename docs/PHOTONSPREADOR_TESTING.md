# PTSD_Photonspreador DevMode 测试

1. 为测试舰装配 `PTSD_Photonspreador`（辉光体）。周围没有受损友方部件时，手动和自动开火都不应产生射击。
2. 损伤射程内的友方武器后，辉光体应自行开火；开火点产生半径 100、持续 1 秒的 RippleOut。
3. 未掉线武器每次恢复最大耐久的 25%；掉线武器解除掉线并至少恢复到 50%，但不会补充弹药。
4. 被修复武器的贴图会产生 0.2 秒紫色错位抖动。
5. 射程内受损引擎遵循相同逻辑：通常恢复 25%，掉线后至少恢复至 50%。系统专用喷口和永久损毁部件不会复原。
6. 独立舰体模块每次恢复最大船体值的 12%；普通舰船船体和装甲不会被修复。
7. 检查敌方部件、射程外部件、装饰武器以及永久损毁武器均不受影响。

射程判定使用武器经过舰船属性修正后的实际 `weapon.getRange()`；当前基础射程为 75。
