## 二、已经确认的联盟成立规则

1. 危机公开后的联盟必须经过邀请流程，不能把所有势力直接默认为成员。
2. 霸主（hegemony）和速子科技（tritachyon）各有殖民地时，永远优先共同发起。
3. 两者只剩一方有殖民地时，该方优先邀请英仙座联盟或卢德教会之一作为共同发起者。二者如何择一仍待确定，建议选择有殖民地且较能支援的一方。
4. 两者都没有殖民地时，由仍有殖民地的英仙座联盟与卢德教会接续；只剩一方则单独发起。均不存在时等待玩家建立联盟或邀请其他有殖民地势力。
5. 独立势力（independent）、英仙座联盟（persean）、辛达（sindrian_diktat）和卢德教会（luddic_church）必定接受邀请。这里的“卢德”不包括左径。
6. 固定成员加入仍呈现“邀请送达—代表团回应—成员生效”；不以随机拒绝破坏必加入要求。已经灭亡且无可用资产的势力是否保留政治席位，待确认；建议不凭空恢复殖民地与军队。
7. 其他势力按关系、威胁、履约与合作成本评估邀请。玩家应有明确加入、拒绝和后续再申请入口，委任派系与玩家自身席位不得重复计票。
8. Gamma保持此前保护规则；联盟不能借战争议案把Gamma当作清剿对象。

## 三、战略救援：用户明确要求

联盟在掌控与实际可支援范围内组织援军。邻近非成员受到入侵时也有较高援助概率，救援不强制对方入盟。

时序：

`收到有效入侵警报 → 等待3日 → 确定来源殖民地并组织 → 各来源原地整备5日 → 前往共同集结点 → 集结后共同出发 → 实际抵达目标 → 援助/交战/撤退`

- 每一步都要能在联盟UI查到当前状态、来源、预计时间与阻塞原因。
- 3日从联盟收到可用警报开始，不能从敌方秘密出发日倒算。重复新闻和重复发现不能重复创建同一救援任务。
- 5日整备在各来源殖民地进行；整备完成仍需实际前往集结点，不能直接传送。
- 集结点优先安全友好殖民地或交通节点，参加部队均实际到达后共同出发。失联/受阻部队需有等待上限或撤销规则，否则整批会无限等待；上限待确认。
- 实际到达目标后才加入防御自动分，途中与集结期间不隔空加成。
- 来源星球被占领、集结点失守、途中遭遇或被玩家改变路线都要有明确转移与取消。
- 目标已经被占领或摧毁：转向该方向附近最近的友好可停泊殖民地。实际到达后驻防30日并计入当地防御；途中不加防御。无安全港则退回来源。此项已确认。
- 30日到期后建议评估继续派遣或返航；不得把同一驻防队再次免费生成一份。

### 建议的响应准则（待确认）

成员领土遇袭自动进入优先队列；玩家遇袭是否受身份、委任与通信条件限制，另定。非成员救援按可达距离、当地威胁、余备和近期承诺作一次持久化评估，失败后在重大局势变化时重评，不逐帧重抽概率。

建议先保证来源最低留守兵力，再承诺外援。每个来源有“可出动、已预留、整备、出航、损失、返航”账目。可用兵力不是殖民地规模简单乘出的无限免费舰队。新增联盟难度参数遵循已确认的自定义难度/DEV可见性规则。

## 四、战斗内求援与自制操作UI

### 用户要求

- 玩家遇袭并进入战斗后，可在TAB指挥界面点击“求救信号”。
- 坚持一定战斗时间后，援军分批入场。
- 来源与实际舰型依附近参与援助的殖民地战斗舰船。
- 援军不占玩家部署点，不挤占玩家可用战场部署容量。
- 支持战场边缘进场，或以抖动、相位般显现模拟横向跃迁。
- 使用自绘UI与自己的请求/入场管理，不把现有按钮换个名字当作完成。

### 两个时间尺度必须分别处理

战役日与战斗秒没有自然一一对应关系。建议战斗内只调用战前已在附近且具备出动条件的部队；远方新组织部队仍遵守3＋5日流程。是否允许远方直接支援战斗的问题已提问，待回复。不得默默把数日行军压缩成几秒。

### 建议面板

TAB画面侧边显示“紧急联络”，分联盟援军与左径信号两块，分别显示来源、编成轮廓、确认/整备/途中/入场状态、预计时间范围和拒绝原因。

- 初始显示是否有可达部队；点击求救后发送一次请求，按钮转为请求状态，重复点击不能刷新或增加兵力。
- 可展开各支援分队：来源殖民地、势力色、预计舰型、可确认的舰数、抵达批次。情报不完整则显示范围。
- 战术地图显示确认中的进入方向、预警落点和已到场友军，不能公开未知敌军坐标。
- 普通编成建议边缘进入；横向跃迁建议由势力技术许可决定，并有入场前预警、短暂到达阶段和安全位置检查。具体选择待回复。
- 建议援军AI自主指挥，玩家可请求守住区域/掩护撤退，但不能把援军永久收编。是否允许直接下达指令仍待确认。
- TAB常伴随暂停，求援等待建议只累计未暂停的战斗时间；按实际墙钟计时会鼓励无限暂停等援军。
- 每批舰船保留唯一身份，实际战损回写来源账本。不能战后复制、瞬间补满或重复发战利品。
- 战斗提前结束、玩家撤离、观战、败退、旗舰被毁及多个友军参战都要定义请求去向，不让增援卡在不存在的战场。

### 技术可行性与验证门槛

本地API提供 `CombatUIAPI.isShowingCommandUI()` 与 `CombatFleetManagerAPI.spawnFleetMember()`，可以识别TAB状态并部署指定成员；这不等于官方已有可直接复用的求援按钮。

零部署占用须验证增援不会改变玩家可部署额度、其他盟军的额度或原版增援列表。不能通过简单提高全场部署上限掩盖占用问题。横向跃迁需要自绘表现及安全出现位置，不把普通舰永久改成相位舰。正式实现前先做最小战斗试验，验证同侧独立舰队、撤退、损失结算和不同分辨率。

## 五、联盟侦察与双方情报对抗

已确认：精神创伤首波开始时，联盟同时开始准备侦察队。实体队完成1处现场侦察，同时免费获得3个附近星系情报（实体1＋虚拟3）。

- 优先联盟有人星系周边、近期受袭方向和陈旧/空白情报区。
- 实地侦察完成后直接上传，不要求活着返航。被击毁不撤销已上传内容，也不补发尚未完成的现场情报。
- 额外3处不得重复、不能读取全星区隐藏部署；不足3个合法邻近目标时只报告现有合法目标。
- 建议实体报告精度较高；虚拟报告带来源、时间戳、置信区间与估算误差。隐藏设施、伏击和伪装队仍需发现，不能以免费报告揭底。
- 玩家地图与联盟数据库分开；是否自动公开全部联盟报告给已入盟玩家，待确认。
- 敌方能截击侦察队以阻止后续报告；已上传情报只能随时间陈旧，不被死亡回调删除。
- 每次报告绑定任务与序号，读档/重入不重抽三个奖励目标、不重复增加侦察贡献。
- 更新按游戏时间和地点索引分批处理，当前现场才做实时传感器检查。

## 六、卢德左径：独立的人类防御保护机制

### 最新已确认规则（取代此前“对所有人友好”的表述）

- 仅在WAR期间启用这套关系规则：对联盟成员友善，对未加入联盟的势力中立，只对精神创伤敌对。
- 左径不加入联盟；成员加入或退出时，其对应关系分类随之更新。玩家关系依玩家实际入盟身份判定，不凭委任自动重复计算。
- 左径可概率性地从无人星系生成舰队，支援附近任何正遭精神创伤攻击的殖民地；受援方是否入盟不构成门槛。
- 该系统面向所有人类，不限玩家或联盟成员。左径会支援正面战场，并概率性冲击精神创伤占领区，以实际反攻吸引其注意力与布防。
- 左径体现宗教狂热和末日危机中的救世使命，成为对人类有益、行动难以完全预测的独立战争力量。不能只表现为玩家专属救命按钮。
- 战斗援军持续多轮抵达，以每场总兵力额度为限，不设固定3轮上限。首轮累计30秒未暂停战斗后抵达，其后每90秒一轮；时间参数可通过LunaLib调整。
- 离屏战场只使用概率战略援军，不触发独立的战斗必到队。玩家实际参与的人类对危机战斗才运行战斗内多轮系统；这不改变战略救援面向所有人类的范围。
- 该系统的定位是额外自生成人类保护机制，尽可能阻滞精神创伤推进，而不是联盟已有额度的一次重新分配。
- 联盟援军、左径战略援军、左径战斗必到援军分为三套独立任务账本。已确认左径两类援军并存，概率战略生成不替代战斗必到。
- 左径援军不扣联盟资源、不替代联盟援军、不减少其他援军的自动分。两类左径援军不能暗中互相扣减额度。
- 精神创伤敌对识别覆盖全部危机势力身份，包括第四窥视；不只检查主势力ID。
- 左径战略援军免费生成，但每个受袭区域限制同时在场/在途支援队数量，并设重试间隔；实际航行，可被击毁，不返还精神创伤资产。以上原则已确认，具体数值待定。
- 从无人星系生成不要求左径当地存在殖民地；生成地本身不能凭此获得左径殖民地或永久基地。

### 建议的执行流程（尚待确认数值与边界）

`确认殖民地遭到危机攻击 → 按受袭区域去重 → 定期进行一次概率判定 → 筛选附近可用无人星系 → 生成左径支援队 → 实际行军 → 到场交战/掩护 → 撤离或转驻 → 清理任务`

1. 以实际入侵或有效警报作为触发依据，不要求玩家在场。救援信息不能读取尚未发现的敌军秘密出发点。
2. 从星域内合法无人星系选择出发地；“任意无人星系可作为候选”与“支援附近目标”同时满足，避免在星区另一端生成永远赶不到的救援。无人范围、支援距离、最大路程仍待设定。
3. 建议优先评估弱势、正在失守、常规援军赶不到的方向；这只是候选优先级，不直接改写战斗胜负。
4. 免费生成、独立记账，按区域限制同时在途/驻防数量及重试频率；兵力上限与频率进入自定义难度。原则已确认，数值仍在讨论。战略限制只约束战略左径队，不扣减战斗必到或联盟支援。
5. 真实航行，可被截击与击毁，到场才增加防御。玩家远离时可按同一份舰队状态模拟，但实体化不能重新抽编成或补满战损。
6. 不把左径的免费部队计为精神创伤可返还资产，不通过反复投影复制舰船，也不将其战损转嫁给联盟。
7. 与联盟3日响应、5日整备不同：左径是独立救援机制，是否有自己的动员时间待确认，不能擅自套用联盟流程。
8. 目标途中失守后的左径行为待确认：可选择掩护邻近撤离、转驻安全殖民地或撤回；不能假装已成功救援。
9. UI显示“左径志愿援军”及已发现的来源/路线/状态，不对玩家暴露“保护机制”“概率补兵”等内部措辞。

### 战斗幸存者与战略队的不同生命周期（已确认）

**战斗内额外援军**：

1. 战斗结束后，按实际幸存舰船生成对应的左径战役舰队；保留舰体、装备、军官、CR和损伤，不能根据剩余FP重新抽一支满血舰队。
2. 只转移本场额外投入的舰船。原有战略左径队保留其原舰队身份，不能再复制进幸存者队。没有幸存舰则不生成空队。
3. 星系内战斗：幸存者在该星系游荡防御10游戏日，之后实际进入超空间，开启加力前往最近友好或中立的人类殖民地，实际抵达后卸载。
4. 超空间战斗：战后直接开启加力，前往最近友好或中立的人类殖民地，实际抵达后卸载，不另驻防10日。
5. 没有合法殖民地时等待并重新选路，不以被精神创伤占领的殖民地作安全终点。目的地途中失守时同样重选。
6. 转为战役队是同一批舰船的继续存在，不增加其他战略救援或反攻的生成额度。实际驻防期间如参与自动分，必须只按幸存实际兵力计入一次，离开后同步扣除。
7. 卸载不返还联盟或精神创伤资产；不把这批免费幸存者转成可重复领取的资源。战斗结束回调重复到达时不能再次生成幸存者队。

**大地图概率救援/反攻队**：

1. 远离玩家时保留虚拟任务和舰队状态；玩家靠近其理论所在位置时实体化。不得仅因玩家靠近目的地，就把仍在远方的舰队提前传送至目标。
2. 一旦实体化，实际前往目标并参与任务；实体与离屏自动分不得同时结算同一支舰队。
3. 任务完成且脱离战斗后立即卸载，不需要先脱离玩家视野。这是用户明确选择，不套用侦察队失联卸载规则。
4. 未实体化的队伍完成任务后直接结束记录。暂时不可见不代表任务完成，不释放仍活跃任务的生成名额。
5. 战略队不采用战斗额外援军的“驻防10日＋到港卸载”流程；两类按来源身份分别处理。

### 主动反攻与敌方应对

**已确认方向**：左径会概率性向精神创伤占领区发动反攻，支援人类正面战场并牵制敌方。反攻不是凭空扣减敌方自动分，而是产生真实或可实体化的行动。

**建议行动差分，尚待审阅**：

|行动|左径实际行为|对人类的帮助|精神创伤可能的应对|
|---|---|---|---|
|赴难驰援|奔赴正在交战的殖民地，先接敌或掩护撤离|为守军与后续联盟队争取时间|识别抵达方向后拦截援军|
|焚械远征|从无人星系出发，攻击已知占领区的运输、外围守军或设施|迫使敌方处理后方威胁，形成前线空档|侦测到威胁后调动已有守军或付费增援，调走部队的原地防御同步减少|
|殉道牵制|进逼较强据点外围，攻击实际防卫单位并尝试引出追击|吸引敌方机动兵力，给人类另一路进攻机会|依据所见敌情判断是否追击，不保证上当，也不能无证据全知识破|
|余火护送|原目标已失守时转而掩护附近撤离船队或安全港|让援军迟到仍有实际价值|追截运输或封锁路径，玩家可以护送与反截击|

- 反攻目标必须来自左径/人类已知的危机占领信息或其实际侦察，不直接读取隐藏母星和设施。
- 用户要求的“混沌”体现在行动方向、时机、编成、敢于深入和不服从联盟调拨；不通过删殖民地、伤害人类或随机改判胜负实现。
- 狂热可表现为在不利兵力比下仍接战、残存舰队掩护最后一批撤离；避免把每个差分都写成同一段冲锋文本。
- 敌方注意力变化来自实际接触与报告。敌方响应必须使用实际守军、调拨及预算，不能一边声称抽调前线、一边保留原地完整防御。
- 已确认反攻独立规则：每10日25％概率判定、全星域同时最多2支反攻队，不占救援区域名额。参数放入DEV自定义难度。任务进行中计入名额，结束或被毁后释放；不因临时投影卸载释放。
- 即使不受联盟指挥，也显示可观察到的出发、接敌、损失、撤离或失联。行动抽签持久化，读档不能刷出更有利的反攻。
- 新增免费左径队不会为任何一方生成退场返还资产；缴获与实际战利品是否需要限制另行实测，不擅自取消原版所有战利品。

- 成员/非成员/危机身份三类关系，以及成员退出、加入后的同步；玩家尚未入盟时也应得到中立而非默认敌对。

- 左径与联盟同时救援时，兵力、预算、贡献、战损和UI分别结算。
- 生成地没有合法候选、路程过长、途中被毁、目标失守和WAR结束有明确等待/结束原因。

## 八、可扩展玩法建议（未获批准，不自动开发）

- **集结暴露**：玩家侦察到敌军准备袭击援军集结点，可以改点或护航；改点真实延误救援。
- **掩护撤离**：目标难守时请求盟军保交通线、掩护难民，而不是无限投兵进必败目标。
- **盟外救援换互信**：救下非成员后出现邀请机会，但不以接受邀请为救援前提。
- **战区通信受扰**：情报延迟和求援ETA出现可解释的不确定性；玩家可保护既有通信设施改善，不重新制造遍地中继节点。
- **职责分工**：来源势力按现有舰型分别承担屏护、远程支援、突击与后撤掩护；不凭空给每个势力相同舰队。
- **救援承诺争端**：迟到、弃援或超额损失形成具体证据与后续议案，不用一条随机扣关系文本替代过程。
