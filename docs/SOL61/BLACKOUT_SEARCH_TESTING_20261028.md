# 大断电：站外搜索与分阶段脉冲（2026-10-28）

## 实施范围

P-09 / STATION_BLACKOUT改为：进入星系建立站外搜索区域→远距不定扫描波→玩家抵达搜索区域→在巡逻传感器之外生成侦察队→从舰队位置发出可见阻断/扫描波，引导玩家继续搜索→实际抵近观测或截击→沿用70秒压制与恢复结算。

这次只修改源码和测试，没有改新闻报道或覆盖加载JAR。没有专门旧档迁移。以下参数为本次实现初值，视觉、节奏和密集巡逻场景仍需实测。

## 导航与交互

- `PTSDSearchAreaNavigation`仅为导航生成无交互的LocationToken，不替换实际目标ID。模拟结算仍可找到空间站，避免把站体压制、现场干扰等逻辑错误作用在空坐标上。
- 大断电：在站体周围优先2000～2800距离选安全空区；到搜索点1400范围内才尝试生成侦察队。空间站不再因该调查加交互任务标记，本站使用正常交互，不打开本事件的采样对话。
- 同类无需逐点交互的火控试探、无应答航迹、要塞巡防空窗也导航到对象附近空区。巡防空窗以实际设施为中心，不以它绑定的跃迁出口为中心。
- 港务核查、弃械船队对话、残骸/记录节点接驳等真正需要互动的任务保留对象导航。跨星系导航仍指向目标星系锚点，进入后从调查列表导航至站外区域。

## 分阶段表现

|阶段|实际行为|不应出现的情况|
|---|---|---|
|玩家未进入星系|持久保留调查；不播放异地画面|异地给玩家叠加闪光|
|进入后、未抵达搜索区|每6～10个未暂停推进秒，在星系四周随机位置发出一圈扫描；米色/紫色交替，波面范围至少18000，必要时扩大以覆盖观察位置|预先生成该事件侦察队、提前压低空间站传感器、提前耗尽70秒过程|
|抵达搜索区|只在安全位置且避开其他非危机流动舰队实际传感器的条件下生成；没有窗口或额度则等待，每3秒最多重试一次|靠“其他舰队忽略我”标记冒充视野外；强制挤入巡逻队传感范围|
|侦察队已生成|保持站外位置；启动传感器扫描，发出紫色较粗阻断波与米色较细扫描波；随后约每6秒重播提示|必须先识别敌舰才能看到引导波；从站体发红圈把玩家引回站体|
|近站压制|保持原来的2800作用距离、传感器压制和70秒过程；生成当帧不补算此前等待时间|抵达就跳过过程；未观测就凭脉冲宣布掌握完整信息|
|玩家截击/站体交战/调查结束|撤销站体传感器修改，沿原生命周期撤离/清理；战斗中的舰队不强制抹除|永久压制、反复计功或取消任务就删除交战舰队|

引导视觉使用原版公开`CampaignPingSpec`与`SectorAPI.addPing`，不自建绘制器。原版ActionIndicator只检查是否处于当前地点，不要求舰队已被玩家识别；因此玩家能看见波面而不会直接得到舰队身份。远距预兆只产生视觉信号，不凭空创建敌舰或改变玩家战备。站外阻断波是事件引导表现，站体实际压制仍由本事件的70秒机制承担，不新增大范围玩家CR损失。

首次侦察调查的通用观察舰不再叠加生成于这个事件。若该事件成为首次调查，复用已经按抵达条件生成且被目击的侦察队。

## 实机验收步骤

1. 将源码编入独立测试版本并重启，开发现场页定向生成P-09属实现场。需要有真实空间站和跃迁出口，且非受保护星系。
2. 进入星系后先停在远处，观察至少30秒：只有大范围米色/紫色扫描，DEV队列中该事件敌舰应为空，70秒压制不推进。暂停时不继续定期播放新波。
3. 从“边缘失联信号”导航，确认目的地是“空间站外搜索空域”，自动航行不会接驳空间站。若在超空间，先进入目标星系，再使用调查导航。
4. 接近标定空区后，检查侦察队在巡逻队视野外生成。密集巡逻情况下允许等待，DEV的lastError会说明当前缺少隐蔽位置或生成额度。
5. 不直接选择敌舰，观察站外方向的两种波面；即使尚未识别舰队也应可见，并能循源接近。不同缩放、显示分辨率和星系布局分别检查，不以离线addPing回调代替视觉验收。
6. 维持观察、提前离开、主动截击分别测试：70秒只在实际生成并进入压制条件后累计；截击打断应恢复站体传感器。已派出舰队的真实战斗不应被调查清理直接删除。
7. 等待阶段保存/重载，搜索点和脉冲序列不重抽；放弃后停止新预兆。顺便检查港口调查/弃械对话仍导航至实际对象，巡防空窗导航落在设施1600～3600的观察带。
