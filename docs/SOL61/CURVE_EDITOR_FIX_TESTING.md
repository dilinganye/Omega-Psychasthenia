# Luna曲线与自定义快照修复验收

## 原因与修复
- 日志确认普通文件写入触发 SecurityException。改用 SettingsAPI 的 common 文件接口，不绕过沙箱。
- 原曲线挂载只由战役脚本轮询。增加Luna设置对话框监听，在设置窗口根面板安装自己的更新器，窗口暂停战役时仍可挂载，切页重建时重新挂载。保留战役轮询作为已打开窗口的补充。
- 专用卡用明确的非空行预留滚动高度，避免空白段落被折叠。四张图全部留在 LunaLib 内；自定义难度页仍是数字输入，曲线编辑页是图形。
- 导出失败会与参数保存失败分开报告，不再错误声称快照已经更新。

## 安装与验证
1. 完全退出游戏，备份加载JAR。测试包位于 build/sol61-curve-ui-export-20261019，替换JAR及所附data配置；开发过程未覆盖加载JAR。
2. 进入战役并开启DEV。打开 LunaLib → Omega-精神创伤 → 曲线编辑（截图最下方的横向页签）。应显示基础难度、舰队增长、战略生产、军官等级四张图；向下滚动查看后两张和保存区。
3. 拖动RECON点，右键增加控制点，Shift+右键删点。两点应为直线，多点平滑。军官限制2至20。增长图下点击封顶/继续增长，应有高亮及提示。
4. 点击底部“应用并保存”；再关开设置并切换页签，确认值保留、图形不重复叠加。
5. 查看 D:/Game/Starsector_098/saves/common/PTSD-custom-difficulty/latest.json.data 与 history。它们都是文本JSON。更改一个值保存，历史新增一份；不改值保存不新增。
6. 切换预设并保存，再切回自定义，确认隐藏参数与曲线恢复。非DEV可用参数修改也应记录完整快照。
7. 若仍没显示，查 starsector.log 是否有 `Mounted four-curve editor in LunaLib` 或 `Luna curve editor unavailable`，提供对应报错和整页截图。

## 验证边界
离线回归覆盖官方保存接口、隐藏字段、历史去重和Luna窗口更新器构建四图，不能代替实际像素布局、鼠标拖动、滚动裁切验收。当前挂载面向进入战役后的Luna窗口，主菜单背景中的Luna窗口尚未接入。
