# 三曲线难度编辑（2026-10-19）

## 当前实现
- 基础难度：沿用原阶段坐标，多点等距平滑；两点线性，阶段边界允许跳变。
- 舰队强度增长率：累计阶段内增长率曲线的积分；1原速，0暂停增长。不是停止舰队生成；基础曲线为0才停止新生成。
- 战略资产生产速度：1原速、0停产，只乘自然资产生产（含星球），不乘运输交付、回收或一次性奖励；战争准备点原规则保留。
- 舰队增长图每个阶段下方 `[>| ]` 封顶、`[>>>]` 继续增长，独立保存。超过本阶段参考时长时，使用增长率末值继续累计；进入下一阶段独立重置。
- RECON默认仍保留阶段时间对应的编成门槛；修改增长率后预算按有效进度与原时间进度的比例调整，舰体解锁按有效进度。超出RECON末端后继续线性扩张强度，不把原来的离散门槛无限重复。
- 曲线编辑位于战役中的LunaLib本模组“曲线编辑”页签，仅DEV可见。嵌入自绘卡片，不修改LunaLib文件。标题界面尚无战役观察器，使用数值字段或载入战役编辑。
- 拖动点调整纵坐标；右键增加等距控制点，Shift+右键减少（2至64）；增删时重新采样旧曲线。阶段图共用纵轴范围，可在底部调整。
- “应用并保存”立即将这些曲线写入自定义难度；“恢复已保存”丢弃本编辑器未应用的修改。编辑其他Luna设置时请先保存，再编辑曲线，避免混用两套未保存草稿。
- 自定义快照：模组目录 `custom-difficulty/latest.json` 及 `custom-difficulty/history/`，普通模式修改可用参数也会保存。无变化不新增历史。

## 默认预设
`data/config/ptsdCSV/PTSD_difficulty_presets.json` 的简单、中等、困难、天灾均增加：
- PTSD_curve_growth_阶段：1,1
- PTSD_curve_production_阶段：1,1
- PTSD_growth_limit_阶段：0（封顶）；1表示继续增长
保留四档之前相同的默认平衡，供作者后续用快照替换。

## 快速验收
1. 备份并安装测试包JAR和预设JSON，启动游戏、载入战役、开启DEV。
2. 打开LunaLib→精神创伤→曲线编辑。确认三图六阶段可见、能滚动，编辑不穿透到底层文本框。
3. 拖动基础RECON控制点；右键加点，Shift右键删点；应用保存，重新打开确认保留。恢复按钮不应自动保存未应用草稿。
4. RECON增长设2,2，选择封顶。阶段结束预算应回到该基础设置下的阶段末强度；切换继续增长则高于阶段末强度。
5. 增长设0,0，保持初期强度；基础设1,0,2，经过0时停止新舰队生成。两种0含义不同。
6. 资产产速设0,0，触发自然生产结算，不增加自然资产；运输交付与回收仍有效。再改2,2比较生产记录。
7. 改完查看custom-difficulty/latest.json和history；重复无修改保存不应增加快照。切预设再切自定义，确认三曲线及每阶段封顶模式保留。
8. 关闭DEV后曲线及内部参数隐藏，已选难度仍生效。
