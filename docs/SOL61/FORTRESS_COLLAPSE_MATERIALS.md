# 黑洞要塞毁灭：材质与云雾重绘（2026-10-21）

## 本次替换
- 删除演出主体的硬边圆盘、无材质弧片、GL直线吸入尾迹和三角形碎片。
- 原版 nebula_colorless、explosion4、particlealpha64sq 与 debris_med1 提供星云、爆炸光、柔光和实际残骸。
- 模组 Particle_Smoke_Dissolve_02、Particle_AE_Shockwave_12、PTSD_trail_noise 提供翻卷烟雾、涡旋与流动环面。
- 云雾采用淡入淡出循环；环面横截面两侧透明衰减，中心保留噪声亮峰，辅以不完全均匀的滚动云团。
- 吸入反色与高潮乘法压暗改为纹理密度遮罩，消除原来的整片灰色硬圆盘。
- 新GLSL材质用相邻纹理采样推导高度梯度及法线，增加凹凸光照。这是本模组的轻量材质着色器，不冒称调用MagicLib的法线API，也未强行在战役侧使用需要CombatEngine的GraphicsLib扭曲接口。
- 着色器不可用时保留贴图加法绘制与软遮罩，不退回线框。素材和shader缓存，循环对象数量固定，无逐帧实体创建。
- 共用战役/战斗绘制入口；90秒时序、20/43/49/73秒伤害波面及CR/D插规则保持。

## 安装
完全退出游戏，备份加载JAR。将本目录 jars 与 data 内文件放到模组对应目录。尤其需要 data/shaders/ptsd_collapse.vert 和 ptsd_collapse.frag；仅换JAR会使用降级显示。开发过程未覆盖加载JAR。
本包以现有加载JAR叠加当前临时编译的生产类，包含此前源码修复；附现有Luna配置和难度预设，不要用包内配置覆盖你尚未备份的手动调参。

## 快速验收
1. 进入专用测试存档，打开DEV“现场模板、舰队与分批测试”。
2. 点击“黑洞毁灭演出预览（无伤害，关闭窗口后播放）”，关闭Intel、解除暂停。
3. 0～32秒检查云雾吸入与材质翻转；32～43秒检查连续暗场过渡；43～65秒检查交错云雾波面；73～90秒检查爆炸、碎块、余烬云及渐隐。
4. 在不同缩放下观察环面有没有接缝、方形贴图边缘、硬切/闪白、同样形状明显重复。暂停应冻结，开Intel或对话不覆盖UI，离开原地点不绘制。
5. 在黑洞星系重复预览，检查与真实吸积盘叠加后的亮度。离屏预览背景不能代替这一项。
6. 正式击毁流程另用独立存档，按 FORTRESS_COLLAPSE_TESTING.md 检查战斗到战役衔接及伤害去重。本次没有增加伤害。
7. 记录前后帧率与峰值卡顿，特别关注贴近核心、多个波面同时存在和最终爆炸；尚未宣称游戏性能达标。

## 已验证与未验证
- 完整临时Java编译通过。
- FortressCollapseTest：伤害下限、无治疗、去重、90秒时序、椭圆波面判定与材质边缘衰减通过。
