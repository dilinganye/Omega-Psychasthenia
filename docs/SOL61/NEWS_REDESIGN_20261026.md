# 2026-10-26 新闻去重复与分阶段验收

## 本批边界与变更

依据 `data/config/ptsdCSV/NEWS_EVENT_AUDIT_20261022.xlsx`、P-08 的 Q32 建议及用户后续确认。原表中的 AI 建议不是全部获准实施的指令，本批仅落实已确认的取舍。保护系列的报道原文、标题、来源和固定剧情没有重写。

- 同一新闻 CSV 追加 `eventWeight`：空白为 1，0 暂停正常投放，其他非负有限值乘原 `weight`。条件入口乘原优先级；Je 入口同样过滤，DEV 指定编号可绕过 0。跨阶段条目的倍率作用于其全部配置阶段。本批未修改 WAR 专属事件；ALL 条目会共同受到倍率影响。
- 51 条重复调查暂禁，逐条记录于 `NEWS_WEIGHT_COVERAGE_20261026.md`。这代表暂缓投放，不代表已完成独特玩法。纯报道不强制变成任务；E2 全部仍为纯报道，不启动旧 E2 现场链。
- 普通可调查新闻改为 90% 属实、10% 不属实。LunaLib 的 DEV「自定义难度 → 普通调查属实概率」为 0～100；字段 `PTSD_news_true_chance`。四个预设均补 90，原有其他预设数值保留。加入完整自定义快照。仅影响新接取调查，明确条件与固定剧情另走原规则。
- RECON 随机入口选择普通填充报道的比例由 52% 调为 25%，提高实际调查接触机会；不是承诺每四条必出一条固定序列。
- 新闻页新增接取后自动打开调查页的开关，每条新新闻默认关闭；开启才跳转。新闻、边缘失联信号正文放大为 21 号，操作按钮高度 30。实际排版仍待不同分辨率验收。
- 新增五个独立模板：`RECON_FIRE_CONTROL`、`RECON_SURRENDER`、`JUMP_BLOCKADE`、`STATION_BLACKOUT`、`DARK_TRANSIT`。要塞巡防缺口改为真实设施与巡逻队的观测窗口；打捞现场残骸位置加入分散。
- 从原版设施菜单返回调查也分派到专属玩法；敌方舰队保留实际接敌，不被通用采样对话截走。

## 最快测试路线

1. 退出游戏，备份原 JAR 和配置后，自行应用 `build/sol61-news-redesign-20261026/package` 内的对应文件。本轮没有覆盖加载 JAR。用专门测试存档，勿以长期主存档验收强制阶段切换。
2. 开启 DEV，进入危机 DEV 控制台，使用「切换到 RECON」。再打开「现场模板、舰队与分批测试」/「[DEV]事件现场与舰队测试」。
3. 上方五个阶段按钮只切换清单，不改变存档实际阶段。需要测试哪个阶段，先在危机控制台切换实际阶段。页面同时显示两者。
4. 点击单条「生成 P-xx 的属实现场」，或输入 `P-08:0` 后先检查前置，再生成。`-1` 为不属实；`0/1/2` 为属实分支。P-08、P-09 只排一个属实分支；P-04 排 0 与 2，避免把相同结果当成额外差分。
5. 点击「导航至实际现场」，关闭 Intel 并解除暂停。DEV 生成会直接记录任务，因此**测试新闻接取和自动跳转开关时**要另外使用危机 DEV 新闻生成入口，不能用已直接接取的现场测试代替。
6. 每项完成后点「清理本次DEV现场（仅自建实体，无奖励）」再生成下一项。正在战斗时拒绝清理；共享设施和真实殖民地保留。封锁的双向航路、站台的传感器修正会恢复。
7. 要批量检查，选择阶段并点「建立所选阶段的启用调查队列」，再逐次「触发下一项」。缺目标会显示等待原因，不会自动制造假的设施；可以跳过。显示暂禁条目后仍可用编号定向测试。

## 配置、界面和回归

- 自然投放不应再出现覆盖表中0权重的**新**调查；旧新闻/已接任务保留。按新闻编号核对，勿把旧存档历史新闻当新投放。
- Luna修改普通调查属实概率后应进入自定义难度；导出包含此字段。快照为游戏 `saves/common/PTSD-custom-difficulty/latest.json.data`（SettingsAPI附加`.data`），不是模组根目录的`latest.json`。
- 设100后接新普通任务验证属实，设0后验证不属实，结束后恢复90。固定条件链不跟随这个测试值。少量随机任务不适合统计90%，概率边界已离线验证。
- 新新闻的自动跳转开关默认关闭；开启后接取才跳转到边缘失联信号，并保留任务定位。两页分别查看长标题、长任务列表和不同窗口宽度，检查字号放大后无溢出。
- 本批编译及14项离线回归通过，见测试包 `regression.txt`。涵盖174条有效CSV、禁用过滤、真实性、地图策略、调查导航、港口入口、扩张争夺、封锁前置与原路恢复、站台计时/中断、隐蔽跟踪与自定义快照。没有运行游戏，实际战斗、视觉、寻路、存档引擎及帧率待验收。
