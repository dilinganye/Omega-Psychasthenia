3. 既有设施和殖民地通过原版规则菜单增加调查选项。同一对象可列出多个事件；不把它们列入场景删除清单。正常贸易/通讯/设施功能不被场景接管。
4. PORT_RECORDS使用星系内实际殖民地；若只有一处合法殖民地，仅取一处记录，不虚构第二颗殖民地。此时一处采样即可归档。

7. 风暴事件：按RECON开始起算每30日一个窗口，仅玩家在实际风暴中移动时消耗当月50％抽签。独立事件队扫描一次、常速撤离，被追踪才紧急推进，连续不可见0.2游戏日后永久卸载。没有战略侦察报告。
8. 事件侦察控制器只管理它自己的舰队，不把普通侦察队和陷阱改为失联卸载。
9. 残骸位置在紧凑范围内随机散布，船体朝向随机。场景仍会避开无法使用的地点。
10. 动员运输和护卫实体航行；出生时6块散落残骸，每2日一次30％机会留下2块残骸，20日自然消散。运输60日仍未到达则作未完成退场，不补给。免费护卫返航不产生额外资产。
11. “未知舰船遭遇”位于新闻分类，持续显示尚存运输并可直接跟踪；记录保留到货/失联结果，不在推送文案泄露内部补给数值。

## 优先实机验收（先用独立测试存档）

### A. 准备与入口

1. 使用本次临时编译结果制作测试版本；加载JAR没有自动覆盖。规则菜单入口必须与新版类同时部署，不能仅安装规则行。
2. 打开DEV控制台 → **现场模板、舰队与分批测试** → **[DEV]事件现场与舰队测试**。
3. 使用新增“定向生成属实现场：编号”按钮。测试按钮会真实生成对象；请不要在正式存档反复触发后继续保存。
4. 每次只测一条。导航到实际现场；需要完整重复验证时重载触发前存档，避免前次事件舰队影响结果。

### B. D-03、JE-01与设施共存

1. 定向生成D-03；记录目标星系内原有中继/传感器/导航设施数量。
2. 前往带黄色叹号的既有设施。应有“调查：标题”选项，同时保留原版设施功能。
3. 再定向生成JE-01。若落到同一个设施，应出现两条独立调查；进入各自选项，内容不得串线。
4. 放弃其中一条，再进入设施：该条入口消失，另一条仍可进入且叹号保留。
5. 完成/放弃全部调查后，原有设施仍存在，不能被场景清理删除。
6. 另选没有上述设施的星系测试补建路径；不能每次进入都再建一座。

### C. 港务档案

1. 定向生成R2-03（港口漏登，PORT_RECORDS）。若当前阶段不适用，先切换RECON。
2. 导航到带叹号的殖民地并实际进入殖民地主菜单，点击调查。不要只打开远程Intel面板。
3. 记录样本后退出，访问同星系其他带标记的殖民地。不得在太空看到“港务封存记录样本”探针。
4. 贸易、通讯和离港仍正常。只有一个合法殖民地的星系不应要求访问不存在的第二处。

### D. 搜索提示、取消与外观

1. 用D-01进入第一处残骸并采样。后续精确定位选项应完全消失；提示应显示还有2处。
2. 自行寻找下一处，采样后显示还有1处及粗略星系提示。重复点击已采样处不能减少计数。
3. 中途存读档；已采样集合、剩余数、差分不变。
4. 在失联信号查看按钮比例、红色悬停反馈、7秒扫描线、滚动时裁剪；窄窗口也不得重叠。
5. 放弃未完成任务：列表清理，无成功奖励；已有追兵不会瞬间消失。Je委托的失败/结案衔接另检查一次。

### E. 四条残骸差分

- D-01：两支实际队伍各自移动检查残骸；发现玩家后撤离，不持续追杀。
- D-02：民用打捞船队穿行数片残骸，不是同一组中继改名。
- D-07：采样前不要出现该事件响应队；第一次采样后从远处来队，发现玩家后撤。反复对话不再刷队。
- D-12：目标应是无人星系小行星带；观察队继续巡查，选它为追踪目标才撤。
- 每项检查残骸散布是否自然且仍能在合理范围找全。自然罕见大型舰差分可以另用定向工具验证，不用等待0.5％随机结果作为首轮通过条件。

### F. 风暴接触

1. 切RECON，进入超空间，点击“风暴侦察测试”。DEV按钮绕过风暴和抽签，但保留编成、扫描、撤离逻辑。
2. 未追踪时观察扫描及常速逃离；以该队为导航/交互目标，观察紧急推进。
3. 保持可见，再失去可见不足0.2日后重新发现：不应卸载，失联计时重置。连续失联0.2日后应卸载。
4. 同时检查普通侦察与陷阱队没有被错误清理；DEV情报中没有该事件产生的侦察上传。
5. 自然触发另测：RECON、真实风暴、航行状态；一个30日窗口只判定一次，读档不能反复抽当月。

### G. 动员、首波与伽马

1. 切动员，保证存在己方据点或要塞。可用“生成一支战前运输”立即创建一批，记录资源数。
2. 在新闻分类打开“未知舰船遭遇”，追踪运输。出生附近应有大残骸带，护卫实际随行。
3. 分叉测试存档：一份截毁运输，另一份护送/等待抵达。前者无到货增益，后者资产与战争点各增加锁定需求的10％，不会因重复更新翻倍。
4. 正式开战后不再每5日新增运输，但途中队伍继续；原有提前开战逻辑保留。
5. 把资源降至不足，推进至动员第30日：应进入WAR。提前准备失败时不得弹出虚构开战新闻。
6. 首波部署不扣资产/战争点，首波存活返航不返还；后续部署扣全额，返航按存活FP的50％。
7. 启用包含Gamma殖民地的指定名单，检查无武装骚扰/首波清剿生成；混合势力星系也应被排除。既有目标结算不能占领Gamma殖民地。
