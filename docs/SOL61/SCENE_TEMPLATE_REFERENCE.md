# 新闻现场模板引用与验收（2026-10-14）

## 接入

唯一事件主表仍为 `data/config/ptsdCSV/PTSD_crisis_news.csv`。`siteTemplates` 用 `|` 分隔候选；仅从满足现场条件的模板中选择并写入事件状态。`JeOnly=TRUE` 由Je私人入口选择，公开随机/条件入口不选取。未知模板拒绝加载该配置，定制处理器失败不回退无关现场。

`PTSDNewsScene.Kind` 显式注册模板；每个事件的 `scene` 持久保存分支、节点、舰队、计时、响应、取证、救援、清理及奖励状态。新任务不做专门旧档迁移。原有专属处理器与FT链保留独立入口。

## 十四类批准模板

|模板|前置与布置|差分与玩家行为|
|---|---|---|
|ROUTE_REVERSAL|真实跃迁口外连续三个航迹节点|记录重放、真实折返、诱导校准；逐点核验，诱导分支完成比对后产生响应|
|ROUTE_DIVERSION|星系外围信号与三处民用残骸|事件幽灵靠近/绕行/阻断；首次进入残骸区一次50%实体化逃离抽签，其他情况消失|
|RELAY_PARASITE|真实中继外附着节点|免费采样、深读、破坏；实秒连接时限、战备脉冲、断线封锁和延迟响应|
|SIGNAL_PURSUIT|可访问未知信号源|保持接通取得完整记录或提前带走部分资料；上传超时、强制断线、封锁、远距接近响应队|
|WRECK_RECONSTRUCTION|三处真实事件废船沿损伤方向分布|第三方向攻击、移动过的船体、仍活动的回收记录；第三分支核验引来响应|
|MISSING_CONVOY|有撤离跃迁口的运输航段|受困船队、空船记录、伪装求援；接应或放弃拖载、回收；实际抵达/损失决定结果|
|FACILITY_INTERDICTION|实际要塞或精神创伤驻站舰队|观察免费；10补给+1日驻留干扰，影响建设阻滞并产生追击|
|SPATIAL_ECHO|三个分离采样位置|重复数据、可复测异常、反向定位；第三分支改变采样顺序触发脉冲与响应|
|FORT_SUPPLY_WINDOW|真实要塞与现存运输舰队|记录交付/损失变化；干扰造成工程阻滞，运输损失提高后续护航，升级上限3|
|FORT_SENSOR_LATTICE|真实要塞与邻近可用星系|三处外围监听节点；一次脉冲与远端响应队；30日退场。公开地图只给外围节点所在星系，不给要塞来源坐标|
|FORT_PATROL_GAP|实际要塞周围巡防区|换防、补给抽调、故意留空；实际守备不足时补足阶段额度；诱导分支靠近引发围捕响应|
|FORT_DECOY_TRANSIT|同一星系两处真实跃迁口|质量对照、延迟重放、运输掩护；指定假目标一次脉冲与战备损失，留下当地势力事件废船|
|FORT_GRAVITY_SURVEY|真实黑洞，三个距离采样位置|校准误差两点证伪；周期变化需完整采样；反向定位第二点启动计时，可下载、退出或破坏；不要求一定已有要塞|
|FORT_SALVAGE_INTERCEPTION|要塞外围、真实撤离出口|救援、记录争夺、无人求援；回收舰实际接近并带走记录，接驳区被控制时不能直接拿走；护送以实际抵达为准|

|TRAFFIC_OBSERVATION|无应答器航行、载货接触向外移动|必须存在真实移动舰队，保存前后段采样；不凭旧坐标宣称实时掌握目的地|

## 生命周期与数值

- 普通取证免费。驻留干扰花费10补给并要求关闭对话后在1800距离内连续1日，离开重置驻留进度，不重复扣补给。
- 深读需要累计12实际秒；连接初始24秒。关闭对话保留剩余值，离场后按游戏日推进（10秒等效/日），不是现实离线计时。超时锁定3游戏日。
- 自毁/诱饵脉冲单次降低最多0.08战备，最低0；不直接删除或毁坏舰船。
- 成功破坏或上传完成共用一次响应标记，0.35游戏日后远端出兵；搜索与追击按实际传感器接触，未发现玩家时不长期绑定玩家坐标。
- 事件舰队受阶段单队/总FP/舰数限制。Je专属响应尝试额外侧翼队，仍受总额度限制；不按玩家等级缩放。
- 阵列响应30日；其他响应、回收、逃离队按创建时指定寿命。永久撤离返还存活FP×0.5，临时卸载/幽灵重建不返还。战斗中的实体延后清理。
- 幽灵出星系卸载，未完成则重入重建。实体化决定只抽一次。仅带显式逃离标记的事件侦察队连续失联0.2游戏日后卸载；普通侦察队和陷阱不套此规则。
- 救援按实际存活船数结算：每艘750星币，回收记录另1500星币，均一次发放；Je原有任务报酬另循原流程。属于首版平衡数值，待实机调整。
- 部分取证为INCONCLUSIVE，不伪装为完全属实。仪器误差为DISPROVED，超时为EXPIRED；完整资料、救援、破坏有不同现场结语。
