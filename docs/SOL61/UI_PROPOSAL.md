## 战线面板

大描述窗口采用原版的深色面板、势力色细边、原版字体和高亮色。顶部显示报告日期、通信状态、当前选中的战区；主体约三分之二为可缩放拖动的星区地图，右侧为选中战区的详情。底部仅保留图层开关、图例和报告过滤，不将地图操作做成一列大按钮。

地图默认显示人类已知星系和已报送战线；敌方部署必须有已知报告支持。星系、舰队和报告的位置分别有来源、记录日期及可靠度；失联后保留末次位置并降低亮度，不随后台实时追踪。无人星系不生成虚构驻军或市场数字，前线附近可显示带日期的方向估计和最近交战。

右键已知星系：`设置防御信标`、`申请盟军增援`、`调动自有/授权后备队`、`规划航线`、`查看相关报告`。没有权限的项目显示原因；没有实际资源的申请进入协商，不即时生成兵力。信标是可撤销的优先请求，地图上显示所属申请人、等待时长和已答复的势力。右键空白区域不提供调兵或信标。

悬停显示简短卡片：星系/市场、报告年龄、已知兵力范围、正在进行的战斗或转运。点击固定该卡片，在右侧展开阵营兵力、补给状态、最近损失和战线纪要。地图线宽表示已确认的行军规模，虚线表示估计或失联；不使用敌方真实攻击权重作为玩家图层。

## 联盟面板

采用“地图与议事台”双主视图，共用成员选择器。地图页呈现部队、战区、增援方向、虚拟战斗与最近军报；议事页呈现成员、席位、提案、逐势力表决、贡献及外交。右侧持续显示选中成员的关系、投入兵力、补给承诺和最近行动。

议事页同时展示四张按成员势力分割的饼图：已投入兵力、有效殖民地数量、累计贡献、最近90日贡献。分母与统计日期始终可见；无数据留空并标记“未报送”，而不是把未知当零。玩家个人功绩单独显示为记录，不再成为一份额外势力切片。玩家殖民地按独立身份计入；佣金贡献按行动发生时归属保留。

提案使用表决条与成员票表：赞成、反对、弃权、尚未答复分列，显示提交时锁定的席位与否决资格。重大联合进攻、大规模跨区调兵、长期补给合同才走正式表决；自有行动和地方应急有独立入口。贿赂入口放在选中成员的地方执行者/港口承包商名单中，先显示资金、承诺资源和保密风险，成交后保留可追溯事件记录。

原版风格占主要视觉空间。TNO式信息密度用于表决和贡献图；CRT效果只作用于军报画面边缘与通信受损的局部，文字区域保持清晰。默认不用整屏闪烁、强色偏或遮挡数字的扫描线。

## 已核对的原版能力

- `TooltipMakerAPI.createSectorMap(...)` 可嵌入原版地图；需要核验能否同时支持本模组的报告过滤和逐星系操作。
- `CustomPanelAPI.createCustomPanel(...)` 与 `CustomUIPanelPlugin` 可提供自绘图层；`InputEventAPI.isMouseDownEvent()/isRMBEvent()` 可处理右键。
- 优先尝试原版地图嵌入；若其封装无法满足过滤/操作，使用自定义地图面板，沿用原版色彩、文字和交互习惯。饼图只使用联盟已报送的快照数据。

上述API可用不代表界面已经完成，也不等于已验证鼠标事件与游戏面板的遮挡、缩放和分辨率兼容。
