# WAR救援与联盟界面验收

## 安装
使用build/sol61-war-rescue-alliance-20261019中的JAR与data配置，退出游戏备份后覆盖对应文件。开发过程未覆盖加载JAR。

## 联盟入口与右键（优先测）
1. 进入WAR或使用已有DEV战区预览，打开“人类联盟：指挥与战线”（原战区态势Intel）。
2. 顶部四页为成员与入伙、议案与表决、调拨与补给、协同防线。确认切页不另开重复地图Intel。
3. 协同防线：右侧不再列九份重复的地理普查及第二张地图，只保留联盟状态、选中区域与真正的活动战线。
4. 点击已知星系，看右侧分行详情；再右键星系节点，应出现可点击的独立菜单，不应为空框。
5. 设置防御信标、撤销、规划航线；有活动战线时测试增援/补给请求。有授权后备队时测试调拨。点地图空白应关闭菜单。
6. 右键靠近地图边缘的星系，确认菜单在窗口内且可滚动。检查普通分隔符不再显示问号。
7. 调拨与补给页保留玩家特化舰队组建入口，不因整合丢失。

界面可在WAR开始后进入；原总参部战争第10日成立和增援资格规则仍在，成立前会显示说明。已有成员/表决/后备队功能，不代表此前全部联盟设计已完成：TAB战斗求援、左径多轮战斗援军、虚拟战略援军等仍未完整实现。无成员殖民地时不可凭空派援。

## 四类救援快捷测试
DEV危机控制台新增“WAR救援测试”四个动作；需要WAR与合法非联盟有人星系，Gamma保护区域排除。
1. 大量残骸：一支受困人类舰队、一支追兵、大范围散布残骸。
2. 少量残骸：一支受困人类舰队、一支追兵、较少残骸。
3. 撤离追逐：3或4支人类逃亡队、两支分别追逐不同目标的危机队。最初选非联盟目的地，无合法目标则选联盟；获救后直接改道联盟。
4. 大型交战：真实人类舰队与危机舰队匹配相同FP，再追击/交战。FP不是实际战术胜率，双方仍受军官、舰型与战损影响。无法合理匹配时生成失败，不伪造分数。

打开新“战时求救”Intel，追踪各人类舰队。进入星系不会自动结束任务。
- 旁观：不发玩家奖励。
- 实际接敌并帮助解围：幸存者脱战且离追兵足够远后，收到感谢；每事件5万至15万星币一次，经验为脱险幸存FP乘250。
- 部分被毁：只计幸存者；测试多队分散、部分已入港、最后一队脱离时的结算。
- 抵达前：不增加联盟后备队。实际到联盟港口后，原舰队成为后备队并继续防御，保留实际损失。
- 港口失守/退出联盟：已获救舰队重新选路；无合法港口不视为抵达。
- 保存读档：奖励、到港登记不重置；90日超时后清理事件追兵，幸存人类队安排撤离。

## 自然触发
仅玩家处于超空间时判定；每10日最多一次、成功率50%、最多3个未结束事件，四类等概率。在星系内不消耗超空间判定窗口，不按漏掉的月份补刷。
参数在DEV自定义难度中：PTSD_rescue_interval/chance/max_active/credit_min/credit_max/xp_per_fp。已写入四档默认预设及自定义快照管理。
