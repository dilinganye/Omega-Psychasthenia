# 2026-08 武器视觉与触发测试

## PTSD_Photonspreador

1. 保留至少 1 发弹药，使辉光体武器被打至掉线。
2. 掉线后应立刻扣除 1 发弹药、强制解除掉线，并在武器位置释放一次完整修复脉冲。
3. 这次自救脉冲应与正常脉冲相同：半径 100、持续 1 秒，同时修复射程内合法部件。
4. 弹药为 0 或永久损毁时不能触发自救。

## PTSD_Fracture_Cross

1. 开火瞬间应是半径 2.5 的标准黑色小球；约 0.42 秒内平滑变为四向带刺裂隙。
2. 完成形变后应能辨认两层边界：主四向裂隙和一层高随机凹陷裂隙。
3. 每枚弹体以 0.2~1 秒随机间隔生成一次暗色云雾，不是每帧生成。
4. 命中后，命中点 20 范围内应有 3 个小裂隙爆开，随后保留原有骇入云效果。

## PTSD_Aftershockor（余波振荡器）

1. 非护盾命中合法舰体后，命中点应持续约 1.5 秒生成品红色、类似原版 Disintegrator 的反向混合烤印。
2. 烤印绑定目标相对坐标，舰船移动和旋转时仍应停留在原命中位置。
3. 烤印只负责视觉，不应在原有一比一额外装甲伤害之外重复造成持续伤害。

## PTSD_Fracture_Calculus

1. 命中合法舰体时只有 5% 概率触发断裂减速；未触发时不消耗塔罗影响。
2. 触发时只消耗当前层数的一半，剩余层数继续保留在目标上；仅剩 1 层时消耗该 1 层。
3. 有引擎的目标：最多 6 个引擎位置出现非圆形品红裂隙迸发，随后进入 5 秒减速。
4. 无引擎目标：目标附近生成暗品红云雾，舰体产生一次约 0.24 秒的品红贴图抖动，随后进入减速。

建议在 DevMode 下分别使用固定高层数目标和无引擎模块目标验证，并观察长时间速射是否出现特效堆积。
# PTSD_Aftershockor 蠕动裂隙

- 弹体仍保持隐藏；飞行中应由双层极坐标裂隙和既有空间扭曲共同表现。
- 外层轮廓的随机凹凸应保持连续，不得逐帧跳变；沿轮廓应能观察到规律传播的褶皱、局部突然收缩以及缓慢呼吸。
- 内层以不同相位、频率和角度错动，使两层轮廓不会完全重合。
- 连续射击时每枚弹体拥有独立但确定的相位；大量弹体不应以完全相同的节拍同步抽动。
- 蠕动裂隙轮廓必须始终显示在移动的随机噪波/反色球上方，噪波只能作为其下层空间扰动背景。
