# 塔罗粒子武器实现与测试

## 行为表

| 武器 | 实际效果 | DevMode 观察 |
| --- | --- | --- |
| `PTSD_Aftershockor` | 非护盾命中普通船体时，读取本次装甲损伤并从命中点周围精确扣除同等装甲。物理弹体、命中辉光和原肢体团均隐藏；飞行期间由重叠Negative效果形成约82～98范围的移动空间扭曲与局部像素反色。 | 目标上方显示本次额外装甲扣除值；观察弹道上只有云迹和反色扭曲，不应出现实体弹丸。 |
| `PTSD_TasloLauncher` | 每次非护盾命中普通舰船增加 1 层“塔罗影响”，使用整数饱和存储，无玩法上限。 | 最多每 0.45 秒显示一次当前层数；正常模式仅在第 1 层及每 25 层显示。 |
| `PTSD_Fracture_Calculus` | 命中后消耗目标当前全部塔罗层数，持续 5 秒降低目标局部时间流速。层数与减速百分比一比一，安全上限为 95%。五秒内再次触发会刷新持续时间，但只采用该窗口内最大的消耗层数。 | 显示消耗层数和实际减速百分比。 |
| `PTSD_Fracture_Volatilizatior` | 每次非护盾命中增加 500 层；增加后总层数严格高于 550 时清空全部层数并触发塔罗塌缩。旧的 `Facture` 弹体 ID 仍由代码兼容，但正式武器与文件均使用 `Fracture`。 | 显示 `+500` 后的层数；塌缩文字显示实际消耗量。 |
| `PTSD_TasloSpinor` | 被动武器，始终禁止主动开火。武器周围600范围常驻下层黑云，并分别生成下层淡裂隙与更小的上层裂隙；每1.45–2.25秒在1000范围索敌。触发时依次产生炮口闪光和局部反色、紫色Shroud电弧，并在电弧抵达后于目标周围200内生成裂隙爆炸。敌舰、LPC战机、导弹、敌方弹体和非友方物理对象均可成为目标，权重严格为 `1000-distance`。 | 最多每秒显示一次风暴与目标距离。 |

## 弹体视觉与性能限制

塔罗弹体物理贴图为 `graphics/None.png`，视觉由 `PTSD_TarotProjectileEffect` 决定：

- 被抽中的弹体使用原版 `RoilingSwarmEffect` 和 `dweller/dweller_pieces`，形成真正的 Shroud 肢体群。
- 未抽中的弹体显示正常塔罗粒子，并按武器分别使用青色冲击、紫色时间断层、蓝紫中和或洋红挥发轨迹。
- 肢体群概率会随武器冷却时间降低。射速高于每秒 4 发后快速降低，因此 `0.01` 秒级武器只抽取约百分之一左右的弹体。
- 全战场最多同时允许约 42 个塔罗弹体肢体群；达到预算后，新弹体只显示普通粒子。
- PTSD_Fracture_Volatilizatior_shot 与旧拼写 PTSD_Facture_Volatilizatior_shot 始终在弹体下层附带三层旋转Negative黑雾，并每0.16～0.24秒留下一个小型下层裂隙；该效果独立于肢体群抽取。
- 除 PTSD_Fracture_Calculus_shot 外，余波、塔罗发射器和挥发场弹道会生成TasloSpinor式黑紫云迹。余波与挥发场逐发生成；0.01秒射击间隔的塔罗发射器按12.5%弹体抽样，以连续观感代替每发创建渲染器。
- 每个肢体群只有 5–12 个原版 Shroud 成员，且不重生；弹体消失后由原版生命周期自动淡出和移除。

## 塔罗影响黑色遮罩

- 遮罩直接调用舰船的 setJitter 顶层效果，不复制舰体贴图，也不建立额外 OpenGL 舰体渲染器。
- 强度采用指数曲线：低层数可见、约 180 层进入明显区间、极高层数在安全透明度内趋于饱和。
- 层数提高时副本数和轻微偏移同步增加；不会改变护盾抖动设置。
- PTSD_Fracture_Calculus 或塔罗塌缩消耗全部层数后，遮罩插件在下一帧自动卸载。

## 建议测试顺序

1. 用带完整装甲的普通巡洋舰承受 `PTSD_Aftershockor`，比较原始装甲损失与黄色 Dev 数字；对护盾命中不应出现额外扣除。
2. 使用 `PTSD_TasloLauncher` 连续命中，确认层数递增且高射速时画面以正常粒子为主、夹杂少量肢体群；舰体会通过原版抖动效果层逐渐覆盖黑色遮罩，层数越高越明显，消耗全部层数后遮罩消失。
3. 累积 20、50、100 层后分别命中 `PTSD_Fracture_Calculus`，确认显示为 20%、50%、95%（安全封顶）且持续 5 秒。
4. 在已有 100 层时命中挥发场：层数变为 600，立即清空并触发洋红色塔罗塌缩。零层开始时第一次命中为 500，不应塌缩；第二次命中应塌缩。
5. 为玩家舰装配 `PTSD_TasloSpinor`，确认600范围黑云和淡裂隙位于舰下，小型稀疏裂隙位于舰上；分别让敌舰、战机、导弹和高射速敌弹进入1000范围，确认炮口反色爆闪、紫色行进电弧、延迟裂隙爆炸的顺序。
6. 同时布置多座高速塔罗武器，长时间战斗观察肢体群数量是否稳定回落、是否存在残留或明显帧率持续下降。

## 关键代码

- `src/data/scripts/weapons/PTSDTarotEffects.java`：层数、精确装甲、时间流、塌缩、风暴和 Dev 文本。
- `src/data/scripts/weapons/PTSD_TarotOnHitEffect.java`：弹体命中分派。
- `src/data/scripts/weapons/PTSD_TarotProjectileEffect.java`：分类视觉、原版肢体群和性能预算。
- `src/data/scripts/weapons/PTSD_TasloSpinorEffect.java`：被动场、下层黑云、空间索敌。
