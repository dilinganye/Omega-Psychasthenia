# 独立新闻DLC示例

这是源代码示例，没有在本体中注册或启用。先阅读 `docs/NEWS_EVENT_API.md` 与 `NewsEventReference.java`。

完整构建好的示例在本体 `build/sol61-news-api-20261028/dlc-example/`。将这个完整目录作为独立模组放入游戏mods，再启用。需要本批新API测试版本；旧加载JAR没有这些类。

事件编号 `DLC_EXAMPLE_01`，RECON阶段。DEV定向生成可绕过随机等待。实际到港核查后完成，正常港口功能保留。此例只用于验证接口，不应原样当作新的高重复任务发布。

修改时使用自己的模组ID、包名、类名、新闻ID及剧情。编译类放进自己的JAR；不能把本体API类重复打包。可以复制完整参考类改造事件树，本示例为了最小化只继承它。
